# Returns and Refunds Policy

This policy decides whether a customer can get a refund for an item bought from our store.

## Return window

1. The return window for an electronics item is 15 days from the purchase date. Electronics items are headphones, laptops, phones, tablets, cameras and smart watches.
2. The return window for any item that is not an electronics item is 30 days from the purchase date.
3. A return request is within the return window if the number of days between the purchase date and the return request is less than or equal to the return window for that item.

## Refund eligibility

4. A customer is eligible for a full refund if all of the following are true: the return request is within the return window, the customer has proof of purchase, the item is not a final sale item, and the item is either unopened or defective.
5. If the return request is not within the return window, the customer is not eligible for a refund.
6. If the customer does not have proof of purchase, the customer is not eligible for a refund.
7. If an item has been opened and is not defective, the customer is not eligible for a refund.
8. Items bought on clearance are final sale items. A final sale item is never eligible for a refund.

## Store credit

9. If the customer does not have proof of purchase, the return request is within the return window, and the item is not a final sale item, the customer is eligible for store credit instead of a refund.

## Refund method

10. If a customer is eligible for a full refund, the refund is issued to the original payment method.

## Contact

Our support team answers refund questions within two working days.
