# policyproof milestone 1 (the reliability core): implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The deterministic core of `policyproof`: YAML policies decoded into a typed syntax tree, validated, compiled
to Z3, used to decide cases and check replies, with every important function backed by a stated law.

**Architecture:** Pure modules of functions over frozen dataclasses (`src/policyproof/core/`), errors as `returns`
`Result` values, Z3 confined to `solver.py`. Laws are Hypothesis property tests against a plain-Python reference
semantics and a brute-force oracle.

**Tech Stack:** Python ≥ 3.13 (developed on 3.14), uv, z3-solver, returns, PyYAML; ty, ruff, pytest, Hypothesis,
import-linter, jsonschema.

**Spec:** `docs/specs/2026-10-03-core-design.md`

**Provenance:** every code block below was run on 2026-10-03 in a scratch copy: 110 tests pass (about 2 minutes),
ruff and ty (3.13 and 3.14) are clean, import-linter keeps the contract and breaks when a core module imports boto3,
and the parity test matches the AgentCore demo on all 20 booking × answer cases.

## Global Constraints

- `requires-python = ">=3.13"`; `.python-version` is `3.14`; ty checks against 3.13 (`[tool.ty.environment]`).
- Runtime dependencies are exactly `z3-solver`, `returns`, `pyyaml`. Extras `anthropic`, `bedrock`, `openai`, `jev`,
  `extract`, `bedrock-ar` are declared empty.
- `policyproof.core` never imports `policyproof.effects`, `boto3`, `botocore`, `anthropic`, `openai`, `langextract`,
  `typesafe`, `httpx` or `requests` (import-linter contract in `pyproject.toml`).
- Data types are `@dataclass(frozen=True, slots=True)`; unions are PEP 695 `type` aliases; every `match` over one of
  our unions ends in `case _: assert_never(x)`.
- `returns`: only `Result`, `Success`, `Failure`, `is_successful`; consume with `.map`, `.bind`, `.alt`, `.lash`,
  `.value_or`, `.unwrap` after a check. No `flow`, `pipe`, `curry`, `RequiresContext` or `Kind`. A `match` on a
  `Result` ends in `case _:` that raises (`core._result.unreachable`), because no checker can prove it exhaustive.
- Modules that define recursive types start with `from __future__ import annotations` (needed on 3.13).
- Suppressions use ty's own codes: `# ty: ignore[<code>]`.
- ruff: line length 120, rules `E, F, I, UP, B, SIM, RUF`.
- Policies are YAML; expressions are YAML trees (operator maps); there is no expression grammar or parser.
- Licence: Apache-2.0.

## Where this plan refines the spec

- `Eq` is `Cmp(op="eq")`; `Cmp` covers `eq ne lt le gt ge`.
- `prove.Verdict` adds `Undetermined(reason)` for when Z3 gives up (non-linear arithmetic, quantifiers).
- Validation: `UnreachableEnumValue` becomes `ImpossibleInput(var, value)` (any Bool or enum input, not only enums),
  and two findings are added: `OverlappingOutcomes(first, second)` (review) and `SolverGaveUp(check, reason)` (error).
- Law L8 (monotonicity) holds when no two outcomes overlap; the validator reports overlaps for review. The airline
  policy has one (free rebooking and "no refund or credit"), so its decisions depend on outcome order, as in the demo.
- `codec.decode`/`from_yaml` return `Result[CheckedPolicy, PolicyError]`, `PolicyError = DecodeError | IllTyped`.
- `explain.Trace` carries a runnable SMT-LIB script and the expected answer (`unsat` for a decision).

## Review Focus

1. Enum values YAML 1.1 reads as booleans (`YES`, `NO`, `ON`, `OFF`): a `DecodeError` at the value's path that says
   to quote it, never a confusing sort error. Pinned in Task 3 (`test_yaml_booleans_as_enum_values_ask_for_quotes`).
2. An unquoted comma or `?` inside `{ }` (easy to write in descriptions and questions): a `DecodeError` with line and
   column and a hint, never a crash. Pinned in Task 3 (`test_an_unquoted_comma_in_a_flow_map_is_...`).
3. Non-linear arithmetic (`mul` of two variables): still decides. Pinned in Task 9
   (`test_non_linear_arithmetic_still_decides`).
4. An askable variable of sort Int (its answers can't be enumerated): asked with an empty what-if table, decided once
   answered. Pinned in Task 9 (`test_an_int_question_has_no_what_if_table_but_is_still_asked`).
5. A policy with no outcomes: `Escalate`, not a crash. Pinned in Task 9 (`test_a_policy_without_outcomes_escalates`).

````markdown
# policyproof

Prove what an agent may decide and say, from a written policy.

A policy is a YAML file: enum sorts, typed variables (from a system, asked of the customer, or derived), rules as
expression trees, and named outcomes. `policyproof` checks the policy is sound, decides cases with the Z3 solver
(or picks the one question that settles them), and checks every claim in an agent's reply against the proof.

```python
````
```python
"""Small helpers over `returns.result.Result` that need no higher-kinded types."""
from collections.abc import Iterable
from typing import NoReturn

from returns.pipeline import is_successful
from returns.result import Failure, Result, Success


def unreachable() -> NoReturn:
    """The last case of a `match` on a `Result`: checkers can't prove `Success | Failure` exhaustive."""
    raise AssertionError("unreachable")


def sequence[T, E](results: Iterable[Result[T, E]]) -> Result[tuple[T, ...], E]:
    """All successes as a tuple, or the first failure. Stops at the first failure."""
    values: list[T] = []
    for r in results:
        if not is_successful(r):
            return Failure(r.failure())
        values.append(r.unwrap())
    return Success(tuple(values))


def errors[T, E](r: Result[T, E]) -> tuple[E, ...]:
    """() for a success, (error,) for a failure: for collecting every error instead of the first."""
    return () if is_successful(r) else (r.failure(),)
```

- [ ] **Step 5: Write the syntax tree** `src/policyproof/core/syntax.py`

```python
"""The policy language as data: sorts, expressions, rules, variables, outcomes and policies.

Only data lives here. Every type is a frozen, slotted dataclass, and every union is closed, so a `match` over one ends
in `assert_never`. Literals are tagged (`BoolLit(True)` is not `IntLit(1)`), so equality is exact.
"""
from __future__ import annotations

from dataclasses import dataclass
from fractions import Fraction
from typing import Literal, NewType

# ---- sorts


@dataclass(frozen=True, slots=True)
class BoolSort:
    pass


@dataclass(frozen=True, slots=True)
class IntSort:
    pass


@dataclass(frozen=True, slots=True)
class RealSort:
    pass


@dataclass(frozen=True, slots=True)
class EnumSort:
    name: str
    values: tuple[str, ...]


type Sort = BoolSort | IntSort | RealSort | EnumSort

BOOL, INT, REAL = BoolSort(), IntSort(), RealSort()

# ---- literals (also the values expressions evaluate to)


@dataclass(frozen=True, slots=True)
class BoolLit:
    value: bool


@dataclass(frozen=True, slots=True)
class IntLit:
    value: int


@dataclass(frozen=True, slots=True)
class RealLit:
    value: Fraction


@dataclass(frozen=True, slots=True)
class EnumLit:
    sort: str
    value: str


type Lit = BoolLit | IntLit | RealLit | EnumLit

# ---- expressions


@dataclass(frozen=True, slots=True)
class Var:
    name: str


@dataclass(frozen=True, slots=True)
class Not:
    arg: Expr


@dataclass(frozen=True, slots=True)
class And:
    args: tuple[Expr, ...]


@dataclass(frozen=True, slots=True)
class Or:
    args: tuple[Expr, ...]


@dataclass(frozen=True, slots=True)
class Implies:
    lhs: Expr
    rhs: Expr


@dataclass(frozen=True, slots=True)
class Iff:
    lhs: Expr
    rhs: Expr


type CmpOp = Literal["eq", "ne", "lt", "le", "gt", "ge"]
CMP_OPS: tuple[CmpOp, ...] = ("eq", "ne", "lt", "le", "gt", "ge")


@dataclass(frozen=True, slots=True)
class Cmp:
    op: CmpOp
    lhs: Expr
    rhs: Expr


type ArithOp = Literal["add", "sub", "mul"]
ARITH_OPS: tuple[ArithOp, ...] = ("add", "sub", "mul")


@dataclass(frozen=True, slots=True)
class Arith:
    op: ArithOp
    args: tuple[Expr, ...]


@dataclass(frozen=True, slots=True)
class In:
    arg: Expr
    values: tuple[Lit, ...]


type Expr = BoolLit | IntLit | RealLit | EnumLit | Var | Not | And | Or | Implies | Iff | Cmp | Arith | In

# ---- rules


@dataclass(frozen=True, slots=True)
class When:
    """`when` implies `then`: the normal rule."""

    id: str
    when: Expr
    then: Expr
    source: str | None = None
    explain: str | None = None


@dataclass(frozen=True, slots=True)
class Define:
    """`var` holds exactly when `as_` holds (if and only if). Listed for review by the validator."""

    id: str
    var: str
    as_: Expr
    source: str | None = None
    explain: str | None = None


@dataclass(frozen=True, slots=True)
class Constraint:
    """A bare assertion. Allowed, but always reported by the validator."""

    id: str
    expr: Expr
    source: str | None = None
    explain: str | None = None


type Rule = When | Define | Constraint

# ---- variables, outcomes, policies


@dataclass(frozen=True, slots=True)
class System:
    """Comes from a system of record; never asked."""


@dataclass(frozen=True, slots=True)
class Ask:
    """Asked of the customer with `question`. A value they only mention in passing is confirmed first."""

    question: str
    confirm_volunteered: bool = True


@dataclass(frozen=True, slots=True)
class Derived:
    """Defined by the rules; never asked and never supplied."""


type Role = System | Ask | Derived


@dataclass(frozen=True, slots=True)
class Variable:
    name: str
    sort: Sort
    role: Role
    description: str


@dataclass(frozen=True, slots=True)
class Outcome:
    """A named result: the conjunction `var == value` over `assignment`. Outcomes are tried in policy order."""

    name: str
    assignment: tuple[tuple[str, Lit], ...]


@dataclass(frozen=True, slots=True)
class Policy:
    name: str
    version: str
    sorts: tuple[EnumSort, ...]
    variables: tuple[Variable, ...]
    rules: tuple[Rule, ...]
    outcomes: tuple[Outcome, ...]


CheckedPolicy = NewType("CheckedPolicy", Policy)
"""A `Policy` that `typecheck.check_policy` accepted. Every core function past decoding takes this type."""


def rule_id(rule: Rule) -> str:
    return rule.id
```

```python
@dataclass(frozen=True, slots=True)

    variables: Mapping[str, Sort]


def signature(p: Policy) -> Signature:
    return Signature({s.name: s for s in p.sorts}, {v.name: v.sort for v in p.variables})

@dataclass(frozen=True, slots=True)
class UnknownName:
    name: str
    where: str


@dataclass(frozen=True, slots=True)
class UnknownValue:
    sort: str
    value: str
    where: str


@dataclass(frozen=True, slots=True)
class SortMismatch:
    expected: str
    got: Sort
    where: str


@dataclass(frozen=True, slots=True)
class BadArity:
    op: str
    got: int
    where: str


@dataclass(frozen=True, slots=True)
class Duplicate:
    kind: str
    name: str


@dataclass(frozen=True, slots=True)
class BadName:
    name: str


type SortError = UnknownName | UnknownValue | SortMismatch | BadArity | Duplicate | BadName


def sort_name(s: Sort) -> str:
    match s:
        case BoolSort():
            return "Bool"
        case IntSort():
            return "Int"
        case RealSort():
            return "Real"
        case EnumSort(name, _):
            return name
        case _:
            assert_never(s)


# ---- expressions


def sort_of(sig: Signature, e: Expr, where: str = "") -> Result[Sort, SortError]:
    match e:
        case BoolLit():
            return Success(BOOL)
        case IntLit():
            return Success(INT)
        case RealLit():
            return Success(REAL)
        case EnumLit(sort, value):
            if sort not in sig.sorts:
                return Failure(UnknownName(sort, where))
            s = sig.sorts[sort]
            return Success(s) if value in s.values else Failure(UnknownValue(sort, value, where))
        case Var(name):
            return Success(sig.variables[name]) if name in sig.variables else Failure(UnknownName(name, where))
        case Not(arg):
            return _expect(sig, arg, BOOL, where)
        case And(args) | Or(args):
            return sequence(_expect(sig, a, BOOL, where) for a in args).map(lambda _: BOOL)
        case Implies(lhs, rhs) | Iff(lhs, rhs):
            return _expect(sig, lhs, BOOL, where).bind(lambda _: _expect(sig, rhs, BOOL, where))
        case Cmp(op, lhs, rhs):
            return sort_of(sig, lhs, where).bind(lambda s: _cmp(sig, op, s, rhs, where))
        case Arith(op, args):
            if len(args) < 1 or (op == "sub" and len(args) != 2):
                return Failure(BadArity(op, len(args), where))
            return sort_of(sig, args[0], where).bind(lambda s: _numeric(s, where)).bind(
                lambda s: sequence(_expect(sig, a, s, where) for a in args[1:]).map(lambda _: s))
        case In(arg, values):
            return sort_of(sig, arg, where).bind(
                lambda s: sequence(_expect(sig, v, s, where) for v in values).map(lambda _: BOOL))
        case _:
            assert_never(e)


def _expect(sig: Signature, e: Expr, want: Sort, where: str) -> Result[Sort, SortError]:
    return sort_of(sig, e, where).bind(
        lambda s: Success(s) if s == want else Failure(SortMismatch(sort_name(want), s, where)))


def _numeric(s: Sort, where: str) -> Result[Sort, SortError]:
    return Success(s) if s in (INT, REAL) else Failure(SortMismatch("Int or Real", s, where))


def _cmp(sig: Signature, op: str, s: Sort, rhs: Expr, where: str) -> Result[Sort, SortError]:
    ordered = _numeric(s, where) if op in ("lt", "le", "gt", "ge") else Success(s)
    return ordered.bind(lambda _: _expect(sig, rhs, s, where)).map(lambda _: BOOL)


# ---- policies


def check_policy(p: Policy) -> Result[CheckedPolicy, tuple[SortError, ...]]:
    sig = signature(p)
    found: list[SortError] = []
    for kind, names in (("sort", [s.name for s in p.sorts]), ("variable", [v.name for v in p.variables]),
                        ("rule", [r.id for r in p.rules]), ("outcome", [o.name for o in p.outcomes])):
        found += [Duplicate(kind, n) for n, k in Counter(names).items() if k > 1]
    found += [BadName(n) for n in [*sig.sorts, *sig.variables] if not NAME.match(n)]
    found += [Duplicate("value", f"{s.name}.{v}") for s in p.sorts for v, k in Counter(s.values).items() if k > 1]
    for v in p.variables:
        if isinstance(v.sort, EnumSort) and sig.sorts.get(v.sort.name) != v.sort:
            found.append(UnknownName(v.sort.name, f"variables.{v.name}"))
    for r in p.rules:
        match r:
            case When(rid, when, then):
                found += errors(_expect(sig, when, BOOL, rid)) + errors(_expect(sig, then, BOOL, rid))
            case Define(rid, var, as_):
                if var not in sig.variables:
                    found.append(UnknownName(var, rid))
                else:
                    found += errors(_expect(sig, as_, sig.variables[var], rid))
            case Constraint(rid, expr):
                found += errors(_expect(sig, expr, BOOL, rid))
            case _:
                assert_never(r)
    for o in p.outcomes:
        for var, value in o.assignment:
            if var not in sig.variables:
                found.append(UnknownName(var, f"outcomes.{o.name}"))
            else:
                found += errors(_expect(sig, value, sig.variables[var], f"outcomes.{o.name}"))
    return Failure(tuple(found)) if found else Success(CheckedPolicy(p))
```

```python
"""The YAML policy format: decoding (with paths and line/column positions) and encoding.

Input is first turned into a small `Tree` (scalars, sequences, maps, each with an optional position), so YAML text and
in-memory data decode through the same code. Strings in, strings out: reading files belongs to `policyproof.effects`.
"""
from __future__ import annotations

from collections.abc import Callable
from dataclasses import dataclass
from fractions import Fraction
from typing import assert_never, cast

import yaml
from returns.result import Failure, Result, Success

from policyproof.core._result import sequence
from policyproof.core.syntax import (

# ---- trees


@dataclass(frozen=True, slots=True)
class Pos:
    line: int  # 1-based
    column: int  # 1-based


type Atom = str | int | float | bool | None


@dataclass(frozen=True, slots=True)
class Scalar:
    value: Atom
    pos: Pos | None = None


@dataclass(frozen=True, slots=True)
class Seq:
    items: tuple[Tree, ...]
    pos: Pos | None = None


@dataclass(frozen=True, slots=True)
class Map:
    items: tuple[tuple[str, Tree], ...]
    pos: Pos | None = None


type Tree = Scalar | Seq | Map
type Data = str | int | bool | list[Data] | dict[str, Data] | None


@dataclass(frozen=True, slots=True)
class DecodeError:
    path: str
    message: str
    pos: Pos | None = None

    def __str__(self) -> str:
        at = f" (line {self.pos.line}, column {self.pos.column})" if self.pos else ""
        return f"{self.path or '<root>'}{at}: {self.message}"


@dataclass(frozen=True, slots=True)
class IllTyped:
    errors: tuple[SortError, ...]


type PolicyError = DecodeError | IllTyped


def from_data(obj: object) -> Result[Tree, DecodeError]:
    """Plain Python data (as from `json.loads` or `yaml.safe_load`) as a tree, without positions."""
    match obj:
        case str() | int() | float() | bool() | None:
            return Success(Scalar(obj))
        case list() | tuple():
            return sequence(from_data(x) for x in cast(list[object], obj)).map(Seq)
        case dict():
            items = cast(dict[object, object], obj).items()
            bad = [k for k, _ in items if not isinstance(k, str)]
            if bad:
                return Failure(DecodeError("", f"map keys must be strings, got {bad[0]!r}"))
            return sequence(from_data(v).map(lambda t, k=k: (str(k), t)) for k, v in items).map(Map)
        case _:
            return Failure(DecodeError("", f"unsupported value {obj!r}"))


def from_yaml_text(text: str) -> Result[Tree, DecodeError]:
    """YAML text as a tree that keeps each node's line and column."""
    try:
        node = yaml.compose(text, Loader=yaml.SafeLoader)
    except yaml.YAMLError as err:
        mark = getattr(err, "problem_mark", None)
        pos = Pos(mark.line + 1, mark.column + 1) if mark is not None else None
        return Failure(DecodeError("", f"invalid YAML: {getattr(err, 'problem', err)}", pos))
    if node is None:
        return Failure(DecodeError("", "the document is empty"))
    return Success(_from_node(node))


def _from_node(node: yaml.Node) -> Tree:
    pos = Pos(node.start_mark.line + 1, node.start_mark.column + 1)
    if isinstance(node, yaml.MappingNode):
        return Map(tuple((str(k.value), _from_node(v)) for k, v in node.value), pos)
    if isinstance(node, yaml.SequenceNode):
        return Seq(tuple(_from_node(x) for x in node.value), pos)
    value = yaml.SafeLoader("").construct_object(node, deep=True)
    return Scalar(value if isinstance(value, str | int | float | bool) or value is None else str(value), pos)


def _err(path: str, t: Tree, message: str) -> Failure[DecodeError]:
    return Failure(DecodeError(path, message, t.pos))


def _join(path: str, key: str | int) -> str:
    return f"{path}[{key}]" if isinstance(key, int) else (f"{path}.{key}" if path else key)


# ---- expressions

UNARY = {"not"}
NARY_BOOL = {"and": And, "or": Or}
BINARY_BOOL = {"implies": Implies, "iff": Iff}


def decode_expr(sig: Signature, t: Tree, path: str = "") -> Result[Expr, DecodeError]:
    match t:
        case Scalar(bool() as b):
            return Success(BoolLit(b))
        case Scalar(int() as n):
            return Success(IntLit(n))
        case Scalar(float()):
            return _err(path, t, 'write decimals as {real: "2.5"}, never as a YAML float')
        case Scalar(str() as name):
            return _name(sig, name, path, t)
        case Scalar(None):
            return _err(path, t, "an expression is missing here")
        case Seq():
            return _err(path, t, "a list is not an expression; use {and: [...]} or {or: [...]}")
        case Map(items) if len(items) != 1:
            return _err(path, t, f"an operator node has exactly one key, found {len(items)}")
        case Map(((op, arg),)):
            return _operator(sig, op, arg, _join(path, op))
        case _:
            raise AssertionError("unreachable")


def _name(sig: Signature, name: str, path: str, t: Tree) -> Result[Expr, DecodeError]:
    if name in sig.variables:
        return Success(Var(name))
    if "." in name:
        sort, _, value = name.partition(".")
        if sort in sig.sorts and value in sig.sorts[sort].values:
            return Success(EnumLit(sort, value))
        return _err(path, t, f"unknown value {name!r}")
    owners = [s.name for s in sig.sorts.values() if name in s.values]
    if len(owners) == 1:
        return Success(EnumLit(owners[0], name))
    if owners:
        return _err(path, t, f"{name!r} is a value of {', '.join(owners)}; qualify it, e.g. {owners[0]}.{name}")
    return _err(path, t, f"unknown name {name!r} (not a variable or an enum value)")


def _operands(arg: Tree, path: str, want: str) -> Result[tuple[Tree, ...], DecodeError]:
    if not isinstance(arg, Seq):
        return _err(path, arg, f"expected a list of {want}")
    n = len(arg.items)
    ok = {"two": n == 2, "two or more": n >= 2, "one or more": n >= 1}[want]
    return Success(arg.items) if ok else _err(path, arg, f"expected {want} operands, found {n}")


def _each(sig: Signature, items: tuple[Tree, ...], path: str) -> Result[tuple[Expr, ...], DecodeError]:
    return sequence(decode_expr(sig, x, _join(path, i)) for i, x in enumerate(items))


def _operator(sig: Signature, op: str, arg: Tree, path: str) -> Result[Expr, DecodeError]:
    if op == "not":
        return decode_expr(sig, arg, path).map(Not)
    if op in NARY_BOOL:
        build = NARY_BOOL[op]
        return _operands(arg, path, "two or more").bind(lambda xs: _each(sig, xs, path)).map(build)
    if op in BINARY_BOOL:
        pair = BINARY_BOOL[op]
        return _operands(arg, path, "two").bind(lambda xs: _each(sig, xs, path)).map(lambda es: pair(es[0], es[1]))
    for cmp in CMP_OPS:
        if op == cmp:
            return _operands(arg, path, "two").bind(lambda xs: _each(sig, xs, path)).map(
                lambda es, c=cmp: Cmp(c, es[0], es[1]))
    for ar in ARITH_OPS:
        if op == ar:
            want = "two" if ar == "sub" else "two or more"
            return _operands(arg, path, want).bind(lambda xs: _each(sig, xs, path)).map(
                lambda es, a=ar: Arith(a, es))
    if op == "in":
        return _operands(arg, path, "two").bind(lambda xs: _membership(sig, xs, path))
    if op == "real":
        return _real(arg, path)
    return _err(path, arg, f"unknown operator {op!r}")


def _membership(sig: Signature, xs: tuple[Tree, ...], path: str) -> Result[Expr, DecodeError]:
    subject, values = xs
    if not isinstance(values, Seq) or not values.items:
        return _err(_join(path, 1), values, "expected a non-empty list of values")
    return decode_expr(sig, subject, _join(path, 0)).bind(
        lambda e: _each(sig, values.items, _join(path, 1)).bind(lambda vs: _literals(vs, values, path)).map(
            lambda lits: In(e, lits)))


def _literals(vs: tuple[Expr, ...], t: Tree, path: str) -> Result[tuple[Lit, ...], DecodeError]:
    lits = tuple(v for v in vs if isinstance(v, BoolLit | IntLit | RealLit | EnumLit))
    return Success(lits) if len(lits) == len(vs) else _err(path, t, "`in` takes literal values only")


def _real(arg: Tree, path: str) -> Result[Expr, DecodeError]:
    if isinstance(arg, Scalar) and isinstance(arg.value, str | int) and not isinstance(arg.value, bool):
        try:
            return Success(RealLit(Fraction(arg.value)))
        except (ValueError, ZeroDivisionError):
            pass
    return _err(path, arg, 'expected a decimal written as a string, e.g. {real: "2.5"} or {real: "5/2"}')


def encode_expr(e: Expr) -> Data:
    match e:
        case BoolLit(v) | IntLit(v):
            return v
        case RealLit(v):
            return {"real": str(v)}
        case EnumLit(sort, value):
            return f"{sort}.{value}"
        case Var(name):
            return name
        case Not(arg):
            return {"not": encode_expr(arg)}
        case And(args):
            return {"and": [encode_expr(a) for a in args]}
        case Or(args):
            return {"or": [encode_expr(a) for a in args]}
        case Implies(lhs, rhs):
            return {"implies": [encode_expr(lhs), encode_expr(rhs)]}
        case Iff(lhs, rhs):
            return {"iff": [encode_expr(lhs), encode_expr(rhs)]}
        case Cmp(op, lhs, rhs):
            return {op: [encode_expr(lhs), encode_expr(rhs)]}
        case Arith(op, args):
            return {op: [encode_expr(a) for a in args]}
        case In(arg, values):
            return {"in": [encode_expr(arg), [encode_expr(v) for v in values]]}
        case _:
            assert_never(e)


# ---- policies


def _field(t: Map, key: str) -> Tree | None:
    return next((v for k, v in t.items if k == key), None)


def _require[T](t: Map, key: str, path: str, read: Callable[[Tree, str], Result[T, DecodeError]]
                ) -> Result[T, DecodeError]:
    v = _field(t, key)
    return read(v, _join(path, key)) if v is not None else _err(path, t, f"missing required key {key!r}")


def _optional[T](t: Map, key: str, path: str, read: Callable[[Tree, str], Result[T, DecodeError]], default: T
                 ) -> Result[T, DecodeError]:
    v = _field(t, key)
    return read(v, _join(path, key)) if v is not None else Success(default)


def _known_keys(t: Map, path: str, allowed: set[str]) -> Result[Map, DecodeError]:
    extra = [(k, v) for k, v in t.items if k not in allowed]
    if not extra:
        return Success(t)
    key, value = extra[0]
    hint = " (a comma inside { } starts a new key: quote text that contains commas)" if value == Scalar(
        None, value.pos) else ""
    return _err(_join(path, key), t, f"unknown key {key!r}{hint}")


def _text(t: Tree, path: str) -> Result[str, DecodeError]:
    if isinstance(t, Scalar) and isinstance(t.value, str):
        return Success(t.value)
    if isinstance(t, Scalar) and isinstance(t.value, bool):
        return _err(path, t, 'YAML reads YES, NO, ON, OFF, TRUE and FALSE as true/false; quote it, e.g. "YES"')
    return _err(path, t, "expected text (quote numbers such as \"1.0\")")


def _flag(t: Tree, path: str) -> Result[bool, DecodeError]:
    if isinstance(t, Scalar) and isinstance(t.value, bool):
        return Success(t.value)
    return _err(path, t, "expected true or false")


def _map(t: Tree, path: str) -> Result[Map, DecodeError]:
    return Success(t) if isinstance(t, Map) else _err(path, t, "expected a map")


def _seq(t: Tree, path: str) -> Result[Seq, DecodeError]:
    return Success(t) if isinstance(t, Seq) else _err(path, t, "expected a list")


def _sorts(t: Tree, path: str) -> Result[tuple[EnumSort, ...], DecodeError]:
    return _map(t, path).bind(lambda m: sequence(
        _seq(v, _join(path, k)).bind(lambda s, k=k: sequence(
            _text(x, _join(_join(path, k), i)) for i, x in enumerate(s.items)).map(lambda vs, k=k: EnumSort(k, vs)))
        for k, v in m.items))


def _sort(sorts: dict[str, EnumSort], t: Tree, path: str) -> Result[Sort, DecodeError]:
    builtin: dict[str, Sort] = {"Bool": BOOL, "Int": INT, "Real": REAL}
    return _text(t, path).bind(lambda n: Success(builtin[n]) if n in builtin else (
        Success(sorts[n]) if n in sorts else _err(path, t, f"unknown sort {n!r}")))


def _role(m: Map, path: str) -> Result[Role, DecodeError]:
    def build(name: str) -> Result[Role, DecodeError]:
        match name:
            case "system":
                return Success(System())
            case "derived":
                return Success(Derived())
            case "ask":
                return _require(m, "question", path, _text).bind(
                    lambda q: _optional(m, "confirm_volunteered", path, _flag, True).map(lambda c: Ask(q, c)))
            case _:
                return _err(_join(path, "role"), m, f"role must be system, ask or derived, not {name!r}")
    return _require(m, "role", path, _text).bind(build)


def _variable(sorts: dict[str, EnumSort], name: str, t: Tree, path: str) -> Result[Variable, DecodeError]:
    keys = {"sort", "role", "description", "question", "confirm_volunteered"}
    return _map(t, path).bind(lambda m: _known_keys(m, path, keys)).bind(lambda m: _require(
        m, "sort", path, lambda x, p: _sort(sorts, x, p)).bind(lambda s: _role(m, path).bind(
            lambda r: _optional(m, "description", path, _text, "").map(lambda d: Variable(name, s, r, d)))))


def _variables(sorts: dict[str, EnumSort], t: Tree, path: str) -> Result[tuple[Variable, ...], DecodeError]:
    return _map(t, path).bind(lambda m: sequence(_variable(sorts, k, v, _join(path, k)) for k, v in m.items))


def _rule(sig: Signature, t: Tree, path: str) -> Result[Rule, DecodeError]:
    keys = {"id", "source", "explain", "when", "then", "define", "constraint"}

    def expr(m: Map, key: str) -> Result[Expr, DecodeError]:
        return _require(m, key, path, lambda x, p: decode_expr(sig, x, p))

    def build(m: Map, rid: str, source: str | None, explain: str | None) -> Result[Rule, DecodeError]:
        shapes = [k for k in ("when", "define", "constraint") if _field(m, k) is not None]
        if len(shapes) != 1:
            return _err(path, m, "a rule has exactly one of: when/then, define, constraint")
        match shapes[0]:
            case "when":
                return expr(m, "when").bind(lambda w: expr(m, "then").map(
                    lambda th: When(rid, w, th, source, explain)))
            case "define":
                dpath = _join(path, "define")
                return _require(m, "define", path, _map).bind(lambda d: _known_keys(d, dpath, {"var", "as"})).bind(
                    lambda d: _require(d, "var", dpath, _text).bind(
                        lambda v: _require(d, "as", dpath, lambda x, p: decode_expr(sig, x, p)).map(
                            lambda a: Define(rid, v, a, source, explain))))
            case _:
                return expr(m, "constraint").map(lambda c: Constraint(rid, c, source, explain))

    def opt_text(m: Map, key: str) -> Result[str | None, DecodeError]:
        return _optional(m, key, path, lambda x, p: _text(x, p).map(lambda s: cast(str | None, s)), None)

    return _map(t, path).bind(lambda m: _known_keys(m, path, keys)).bind(lambda m: _require(m, "id", path, _text).bind(
        lambda rid: opt_text(m, "source").bind(lambda src: opt_text(m, "explain").bind(
            lambda ex: build(m, rid, src, ex)))))


def _outcome(sig: Signature, name: str, t: Tree, path: str) -> Result[Outcome, DecodeError]:
    def literal(var: str, x: Tree) -> Result[tuple[str, Lit], DecodeError]:
        p = _join(path, var)
        return decode_expr(sig, x, p).bind(lambda e: Success((var, e)) if isinstance(
            e, BoolLit | IntLit | RealLit | EnumLit) else _err(p, x, "an outcome assigns literal values only"))
    return _map(t, path).bind(lambda m: sequence(literal(k, v) for k, v in m.items)).map(lambda a: Outcome(name, a))


def decode_tree(t: Tree) -> Result[Policy, DecodeError]:
    """The structural decoding of a policy, before sort checking."""
    keys = {"policy", "version", "sorts", "variables", "rules", "outcomes"}

    def body(m: Map, name: str, version: str, sorts: tuple[EnumSort, ...]) -> Result[Policy, DecodeError]:
        def with_variables(vs: tuple[Variable, ...]) -> Result[Policy, DecodeError]:
            sig = signature(Policy(name, version, sorts, vs, (), ()))
            rules = _require(m, "rules", "", lambda x, p: _seq(x, p).bind(
                lambda s: sequence(_rule(sig, r, _join(p, i)) for i, r in enumerate(s.items))))
            return rules.bind(lambda rs: _optional(m, "outcomes", "", lambda x, p: _map(x, p).bind(
                lambda om: sequence(_outcome(sig, k, v, _join(p, k)) for k, v in om.items)), ()).map(
                lambda os: Policy(name, version, sorts, vs, rs, os)))

        by_name = {s.name: s for s in sorts}
        return _require(m, "variables", "", lambda x, p: _variables(by_name, x, p)).bind(with_variables)

    return _map(t, "").bind(lambda m: _known_keys(m, "", keys)).bind(lambda m: _require(m, "policy", "", _text).bind(
        lambda name: _require(m, "version", "", _text).bind(lambda version: _optional(
            m, "sorts", "", _sorts, ()).bind(lambda sorts: body(m, name, version, sorts)))))


def _checked(r: Result[Policy, DecodeError]) -> Result[CheckedPolicy, PolicyError]:
    return r.alt(lambda e: cast(PolicyError, e)).bind(
        lambda p: check_policy(p).alt(lambda errs: cast(PolicyError, IllTyped(errs))))


def decode(data: object) -> Result[CheckedPolicy, PolicyError]:
    """A checked policy from plain data (e.g. `json.loads` output)."""
    return _checked(from_data(data).bind(decode_tree))


def from_yaml(text: str) -> Result[CheckedPolicy, PolicyError]:
    """A checked policy from YAML text; decode errors carry line and column."""
    return _checked(from_yaml_text(text).bind(decode_tree))


def _encode_sort(s: Sort) -> str:
    match s:
        case BoolSort():
            return "Bool"
        case IntSort():
            return "Int"
        case RealSort():
            return "Real"
        case EnumSort(name, _):
            return name
        case _:
            assert_never(s)


def _encode_variable(v: Variable) -> dict[str, Data]:
    out: dict[str, Data] = {"sort": _encode_sort(v.sort)}
    match v.role:
        case System():
            out["role"] = "system"
        case Derived():
            out["role"] = "derived"
        case Ask(question, confirm):
            out |= {"role": "ask", "question": question, "confirm_volunteered": confirm}
        case _:
            assert_never(v.role)
    out["description"] = v.description
    return out


def _encode_rule(r: Rule) -> dict[str, Data]:
    out: dict[str, Data] = {"id": r.id}
    if r.source is not None:
        out["source"] = r.source
    match r:
        case When(_, when, then):
            out |= {"when": encode_expr(when), "then": encode_expr(then)}
        case Define(_, var, as_):
            out["define"] = {"var": var, "as": encode_expr(as_)}
        case Constraint(_, expr):
            out["constraint"] = encode_expr(expr)
        case _:
            assert_never(r)
    if r.explain is not None:
        out["explain"] = r.explain
    return out


def encode(p: Policy) -> dict[str, Data]:
    return {
        "policy": p.name,
        "version": p.version,
        "sorts": {s.name: list(s.values) for s in p.sorts},
        "variables": {v.name: _encode_variable(v) for v in p.variables},
        "rules": [_encode_rule(r) for r in p.rules],
        "outcomes": {o.name: {var: encode_expr(lit) for var, lit in o.assignment} for o in p.outcomes},
    }


def to_yaml(p: Policy) -> str:
    return yaml.safe_dump(encode(p), sort_keys=False, allow_unicode=True, width=120)
```

```python
"""JSON Schema (2020-12) for the YAML policy format.

`build()` is the source of truth; `policy.schema.json` is its output, shipped for non-Python tools and checked by a
test. Regenerate with `uv run python -m policyproof.schema`.
"""
import json
from pathlib import Path

PATH = Path(__file__).with_name("policy.schema.json")
EXPR = {"$ref": "#/$defs/expr"}


def _op(name: str, body: object) -> dict[str, object]:
    return {"type": "object", "required": [name], "additionalProperties": False, "properties": {name: body}}


def _nary(name: str) -> dict[str, object]:
    return _op(name, {"type": "array", "minItems": 2, "items": EXPR})


def _binary(name: str) -> dict[str, object]:
    return _op(name, {"type": "array", "minItems": 2, "maxItems": 2, "items": EXPR})


def build() -> dict[str, object]:
    literal_list = {"type": "array", "minItems": 1, "items": {"$ref": "#/$defs/literal"}}
    return {
        "$schema": "https://json-schema.org/draft/2020-12/schema",
        "$id": "urn:policyproof:policy:1",
        "title": "policyproof policy",
        "description": "Enum sorts, typed variables with roles, rules as expression trees, and named outcomes.",
        "type": "object",
        "required": ["policy", "version", "variables", "rules"],
        "additionalProperties": False,
        "properties": {
            "policy": {"type": "string"},
            "version": {"type": "string"},
            "sorts": {"type": "object", "propertyNames": {"$ref": "#/$defs/name"},
                      "additionalProperties": {"type": "array", "minItems": 1, "items": {"type": "string"}}},
            "variables": {"type": "object", "propertyNames": {"$ref": "#/$defs/name"},
                          "additionalProperties": {"$ref": "#/$defs/variable"}},
            "rules": {"type": "array", "items": {"$ref": "#/$defs/rule"}},
            "outcomes": {"type": "object", "additionalProperties": {
                "type": "object", "minProperties": 1, "additionalProperties": {"$ref": "#/$defs/literal"}}},
        },
        "$defs": {
            "name": {"type": "string", "pattern": "^[A-Za-z_][A-Za-z0-9_]*$"},
            "variable": {
                "type": "object", "required": ["sort", "role"], "additionalProperties": False,
                "properties": {"sort": {"type": "string"}, "role": {"enum": ["system", "ask", "derived"]},
                               "description": {"type": "string"}, "question": {"type": "string"},
                               "confirm_volunteered": {"type": "boolean"}},
                "if": {"properties": {"role": {"const": "ask"}}}, "then": {"required": ["question"]},
            },
            "rule": {
                "type": "object", "required": ["id"], "additionalProperties": False,
                "properties": {"id": {"type": "string"}, "source": {"type": "string"}, "explain": {"type": "string"},
                               "when": EXPR, "then": EXPR, "constraint": EXPR,
                               "define": {"type": "object", "required": ["var", "as"], "additionalProperties": False,
                                          "properties": {"var": {"type": "string"}, "as": EXPR}}},
                "oneOf": [{"required": ["when", "then"]}, {"required": ["define"]}, {"required": ["constraint"]}],
            },
            "real": _op("real", {"type": ["string", "integer"]}),
            "literal": {"anyOf": [{"type": "boolean"}, {"type": "integer"}, {"type": "string"},
                                  {"$ref": "#/$defs/real"}]},
            "expr": {"anyOf": [
                {"type": "boolean"}, {"type": "integer"}, {"type": "string"}, {"$ref": "#/$defs/real"},
                _op("not", EXPR), _nary("and"), _nary("or"), _binary("implies"), _binary("iff"),
                *[_binary(c) for c in ("eq", "ne", "lt", "le", "gt", "ge", "sub")], _nary("add"), _nary("mul"),
                _op("in", {"type": "array", "minItems": 2, "maxItems": 2, "prefixItems": [EXPR, literal_list]}),
            ]},
        },
    }


def load() -> dict[str, object]:
    return json.loads(PATH.read_text())


def write() -> None:
    PATH.write_text(json.dumps(build(), indent=2) + "\n")
```

```python
"""Hypothesis strategies: well-typed expressions, total environments and whole policies over one fixed signature."""
from dataclasses import replace
from functools import cache

from hypothesis import strategies as st

from policyproof.core.syntax import (
    BOOL,
    CMP_OPS,
    INT,
    REAL,
    And,
    Arith,
    Ask,
    BoolLit,
    BoolSort,
    Cmp,
    CmpOp,
    Constraint,
    Define,
    Derived,
    EnumLit,
    EnumSort,
    Expr,
    Iff,
    Implies,
    In,
    IntLit,
    IntSort,
    Lit,
    Not,
    Or,
    Outcome,
    Policy,
    RealLit,
    RealSort,
    Rule,
    Sort,
    System,
    Var,
    Variable,
    When,
)
from policyproof.core.typecheck import Signature

COLOR = EnumSort("Color", ("RED", "GREEN", "BLUE"))
VARS: dict[str, Sort] = {"p": BOOL, "q": BOOL, "r": BOOL, "m": INT, "n": INT, "x": REAL, "c": COLOR}
SIG = Signature({"Color": COLOR}, VARS)


def literals(s: Sort) -> st.SearchStrategy[Lit]:
    match s:
        case BoolSort():
            return st.booleans().map(BoolLit)
        case IntSort():
            return st.integers(-4, 4).map(IntLit)
        case RealSort():
            return st.fractions(-4, 4, max_denominator=4).map(RealLit)
        case EnumSort(name, values):
            return st.sampled_from(values).map(lambda v: EnumLit(name, v))
        case _:
            raise AssertionError(s)


def variables_of(s: Sort) -> st.SearchStrategy[Expr]:
    return st.sampled_from([n for n, t in VARS.items() if t == s]).map(Var)


@cache
def exprs(s: Sort, depth: int = 3, finite: bool = False) -> st.SearchStrategy[Expr]:
    """Well-typed expressions of sort `s` over `SIG`, at most `depth` operators deep. With `finite`, only the
    Bool and Color variables occur, so every world can be enumerated."""
    leaves: st.SearchStrategy[Expr] = st.one_of(literals(s), variables_of(s))
    if depth == 0 or isinstance(s, EnumSort):
        return leaves

    def sub(t: Sort) -> st.SearchStrategy[Expr]:
        return exprs(t, depth - 1, finite)

    def cmp(ops: tuple[CmpOp, ...], t: Sort) -> st.SearchStrategy[Expr]:
        return st.tuples(st.sampled_from(ops), sub(t), sub(t)).map(lambda a: Cmp(a[0], a[1], a[2]))

    if isinstance(s, BoolSort):
        pairs = st.tuples(sub(BOOL), sub(BOOL))
        many = st.lists(sub(BOOL), min_size=2, max_size=3).map(tuple)
        finite_ops = [
            sub(BOOL).map(Not), many.map(And), many.map(Or),
            pairs.map(lambda t: Implies(*t)), pairs.map(lambda t: Iff(*t)),
            cmp(("eq", "ne"), BOOL), cmp(("eq", "ne"), COLOR),
            st.tuples(sub(COLOR), st.lists(literals(COLOR), min_size=1, max_size=3, unique=True)).map(
                lambda t: In(t[0], tuple(t[1]))),
        ]
        numeric_ops = [
            cmp(CMP_OPS, INT), cmp(CMP_OPS, REAL),
            st.tuples(sub(INT), st.lists(literals(INT), min_size=1, max_size=3, unique=True)).map(
                lambda t: In(t[0], tuple(t[1]))),
        ]
        compound = st.one_of(*finite_ops, *([] if finite else numeric_ops))
    else:
        compound = st.one_of(
            st.tuples(st.sampled_from(("add", "mul")), st.lists(sub(s), min_size=2, max_size=3)).map(
                lambda t: Arith(t[0], tuple(t[1]))),
            st.tuples(sub(s), sub(s)).map(lambda t: Arith("sub", t)),
        )
    return st.one_of(leaves, compound)


def envs() -> st.SearchStrategy[dict[str, Lit]]:
    """Total environments: a value for every variable in `SIG`."""
    return st.fixed_dictionaries({n: literals(s) for n, s in VARS.items()})


TEXT = st.text(st.characters(categories=("L", "N", "P", "Zs")), max_size=12)
DECLS = (Variable("p", BOOL, Ask("P?"), "asked"), Variable("q", BOOL, System(), ""),
         Variable("r", BOOL, Derived(), ""), Variable("m", INT, System(), ""), Variable("n", INT, System(), ""),
         Variable("x", REAL, System(), ""), Variable("c", COLOR, System(), ""))


def rules(finite: bool = False) -> st.SearchStrategy[Rule]:
    e = exprs(BOOL, 2, finite)
    meta = st.tuples(st.none() | TEXT, st.none() | TEXT)
    return st.one_of(
        st.tuples(e, e, meta).map(lambda t: When("", t[0], t[1], *t[2])),
        st.tuples(e, meta).map(lambda t: Define("", "r", t[0], *t[1])),

        Outcome(f"o{i}", tuple((v, BoolLit(b)) for v, b in a)) for i, a in enumerate(os)))
    return st.builds(Policy, name=TEXT, version=TEXT, sorts=st.just((COLOR,)), variables=st.just(DECLS),
                     rules=numbered, outcomes=outcomes)
```

```python
"""Display forms of expressions: a readable one-line form, and SMT-LIB. Nothing parses these back."""
from __future__ import annotations

from typing import assert_never

from policyproof.core.syntax import (
    And,
    Arith,
    BoolLit,
    BoolSort,
    Cmp,
    EnumLit,
    EnumSort,
    Expr,
    Iff,
    Implies,
    In,
    IntLit,
    IntSort,
    Not,
    Or,
    RealLit,
    RealSort,
    Var,
)
from policyproof.core.typecheck import Signature

CMP_SYMBOL = {"eq": "=", "ne": "≠", "lt": "<", "le": "≤", "gt": ">", "ge": "≥"}
ARITH_SYMBOL = {"add": "+", "sub": "−", "mul": "×"}
ATOM = 9


def _prec(e: Expr) -> int:
    match e:
        case Iff():
            return 1
        case Implies():
            return 2
        case Or():
            return 3
        case And():
            return 4
        case Not():
            return 5
        case Cmp() | In():
            return 6
        case Arith(op, _):
            return 8 if op == "mul" else 7
        case BoolLit() | IntLit() | RealLit() | EnumLit() | Var():
            return ATOM
        case _:
            assert_never(e)


def _wrap(e: Expr, parent: int) -> str:
    text = pretty(e)
    return f"({text})" if _prec(e) <= parent and _prec(e) != ATOM else text


def pretty(e: Expr) -> str:
    """`delayHours ≥ 3 ∧ ¬hasFlown`: for explanations and traces."""
    match e:
        case BoolLit(v):
            return "true" if v else "false"
        case IntLit(v):
            return str(v)
        case RealLit(v):
            return str(v)
        case EnumLit(_, value):
            return value
        case Var(name):
            return name
        case Not(arg):
            return f"¬{_wrap(arg, ATOM - 1)}"
        case And(args):
            return " ∧ ".join(_wrap(a, 4) for a in args)
        case Or(args):
            return " ∨ ".join(_wrap(a, 3) for a in args)
        case Implies(lhs, rhs):
            return f"{_wrap(lhs, 2)} ⇒ {_wrap(rhs, 2)}"
        case Iff(lhs, rhs):
            return f"{_wrap(lhs, 1)} ⇔ {_wrap(rhs, 1)}"
        case Cmp(op, lhs, rhs):
            return f"{_wrap(lhs, 6)} {CMP_SYMBOL[op]} {_wrap(rhs, 6)}"
        case Arith(op, args):
            return f" {ARITH_SYMBOL[op]} ".join(_wrap(a, _prec(e)) for a in args)
        case In(arg, values):
            return f"{_wrap(arg, 6)} ∈ {{{', '.join(pretty(v) for v in values)}}}"
        case _:
            assert_never(e)


def smt_name(sort: str, value: str) -> str:
    """The SMT-LIB and Z3 name of an enum value; qualified, because two sorts may share a value name."""
    return f"{sort}.{value}"


def to_smtlib(e: Expr) -> str:
    match e:
        case BoolLit(v):
            return "true" if v else "false"
        case IntLit(v):
            return str(v) if v >= 0 else f"(- {-v})"
        case RealLit(v):
            n, d = abs(v.numerator), v.denominator
            body = f"(/ {n}.0 {d}.0)" if d != 1 else f"{n}.0"
            return body if v >= 0 else f"(- {body})"
        case EnumLit(sort, value):
            return f"|{smt_name(sort, value)}|"
        case Var(name):
            return name
        case Not(arg):
            return f"(not {to_smtlib(arg)})"
        case And(args):
            return f"(and {' '.join(map(to_smtlib, args))})" if args else "true"
        case Or(args):
            return f"(or {' '.join(map(to_smtlib, args))})" if args else "false"
        case Implies(lhs, rhs):
            return f"(=> {to_smtlib(lhs)} {to_smtlib(rhs)})"
        case Iff(lhs, rhs):
            return f"(= {to_smtlib(lhs)} {to_smtlib(rhs)})"
        case Cmp("ne", lhs, rhs):
            return f"(distinct {to_smtlib(lhs)} {to_smtlib(rhs)})"
        case Cmp(op, lhs, rhs):
            symbol = {"eq": "=", "lt": "<", "le": "<=", "gt": ">", "ge": ">="}[op]
            return f"({symbol} {to_smtlib(lhs)} {to_smtlib(rhs)})"
        case Arith(op, args):
            return f"({ {'add': '+', 'sub': '-', 'mul': '*'}[op]} {' '.join(map(to_smtlib, args))})"
        case In(arg, values):
            x = to_smtlib(arg)
            return f"(or {' '.join(f'(= {x} {to_smtlib(v)})' for v in values)})" if len(values) > 1 else (
                f"(= {x} {to_smtlib(values[0])})")
        case _:
            assert_never(e)


def smt_declarations(sig: Signature) -> str:
    """`declare-datatypes` for the enum sorts and `declare-const` for the variables."""
    lines = [f"(declare-datatypes () (({s.name} {' '.join(f'|{smt_name(s.name, v)}|' for v in s.values)})))"
             for s in sig.sorts.values()]
    for name, sort in sig.variables.items():
        match sort:
            case BoolSort():
                smt = "Bool"
            case IntSort():
                smt = "Int"
            case RealSort():
                smt = "Real"
            case EnumSort(sname, _):
                smt = sname
            case _:
                assert_never(sort)
        lines.append(f"(declare-const {name} {smt})")
    return "\n".join(lines)
```

```python
"""The reference semantics: evaluation, substitution, free variables and simplification.

Independent of Z3 on purpose. The laws (compile soundness, simplification) are stated against `evaluate`, so Z3 is
checked against a few lines of plain Python rather than trusted.
"""
from __future__ import annotations

from collections.abc import Callable, Mapping
from dataclasses import dataclass
from fractions import Fraction
from functools import reduce
from operator import add, mul, sub
from typing import assert_never

from returns.result import Failure, Result, Success

from policyproof.core._result import sequence
from policyproof.core.syntax import (
    And,
    Arith,
    BoolLit,
    Cmp,
    Constraint,
    Define,
    EnumLit,
    Expr,
    Iff,
    Implies,
    In,
    IntLit,
    Lit,
    Not,
    Or,
    RealLit,
    Rule,
    Var,
    When,
)

type Env = Mapping[str, Lit]


@dataclass(frozen=True, slots=True)
class Unbound:
    name: str


@dataclass(frozen=True, slots=True)
class Mismatch:
    expected: str
    got: Lit


type EvalError = Unbound | Mismatch


def _bool(e: Expr, env: Env) -> Result[bool, EvalError]:
    return evaluate(e, env).bind(lambda v: Success(v.value) if isinstance(v, BoolLit) else Failure(Mismatch("Bool", v)))


def _num(v: Lit) -> Result[int | Fraction, EvalError]:
    match v:
        case IntLit(n) | RealLit(n):
            return Success(n)
        case _:
            return Failure(Mismatch("Int or Real", v))


def _same_kind(vs: tuple[Lit, ...]) -> Result[tuple[Lit, ...], EvalError]:
    first = type(vs[0])
    odd = next((v for v in vs if type(v) is not first), None)
    return Failure(Mismatch(first.__name__.removesuffix("Lit"), odd)) if odd is not None else Success(vs)


def _arith(op: str, vs: tuple[Lit, ...]) -> Result[Lit, EvalError]:
    fn: Callable[[int | Fraction, int | Fraction], int | Fraction] = {"add": add, "sub": sub, "mul": mul}[op]
    return _same_kind(vs).bind(lambda same: sequence(_num(v) for v in same)).map(lambda ns: _wrap_num(
        vs[0], reduce(fn, ns)))


def _wrap_num(like: Lit, n: int | Fraction) -> Lit:
    return IntLit(int(n)) if isinstance(like, IntLit) else RealLit(Fraction(n))


def _compare(op: str, a: Lit, b: Lit) -> Result[bool, EvalError]:
    if op == "eq":
        return Success(a == b)
    if op == "ne":
        return Success(a != b)
    ordered: dict[str, Callable[[int | Fraction, int | Fraction], bool]] = {
        "lt": lambda x, y: x < y, "le": lambda x, y: x <= y, "gt": lambda x, y: x > y, "ge": lambda x, y: x >= y}
    return _num(a).bind(lambda x: _num(b).map(lambda y: ordered[op](x, y)))


def evaluate(e: Expr, env: Env) -> Result[Lit, EvalError]:
    """The value of `e` under `env`. Strict: every variable that occurs must be bound."""
    match e:
        case BoolLit() | IntLit() | RealLit() | EnumLit():
            return Success(e)
        case Var(name):
            return Success(env[name]) if name in env else Failure(Unbound(name))
        case Not(arg):
            return _bool(arg, env).map(lambda b: BoolLit(not b))
        case And(args):
            return sequence(_bool(a, env) for a in args).map(lambda bs: BoolLit(all(bs)))
        case Or(args):
            return sequence(_bool(a, env) for a in args).map(lambda bs: BoolLit(any(bs)))
        case Implies(lhs, rhs):
            return _bool(lhs, env).bind(lambda a: _bool(rhs, env).map(lambda b: BoolLit(not a or b)))
        case Iff(lhs, rhs):
            return _bool(lhs, env).bind(lambda a: _bool(rhs, env).map(lambda b: BoolLit(a == b)))
        case Cmp(op, lhs, rhs):
            return evaluate(lhs, env).bind(lambda a: evaluate(rhs, env).bind(
                lambda b: _compare(op, a, b))).map(BoolLit)
        case Arith(op, args):
            return sequence(evaluate(a, env) for a in args).bind(lambda vs: _arith(op, vs))
        case In(arg, values):
            return evaluate(arg, env).map(lambda v: BoolLit(v in values))
        case _:
            assert_never(e)


def rule_expr(r: Rule) -> Expr:
    """What a rule asserts, as one Boolean expression."""
    match r:
        case When(_, when, then):
            return Implies(when, then)
        case Define(_, var, as_):
            return Cmp("eq", Var(var), as_)
        case Constraint(_, expr):
            return expr
        case _:
            assert_never(r)


def substitute(e: Expr, env: Env) -> Expr:
    """`e` with every variable bound in `env` replaced by its value."""
    match e:
        case BoolLit() | IntLit() | RealLit() | EnumLit():
            return e
        case Var(name):
            return env.get(name, e)
        case Not(arg):
            return Not(substitute(arg, env))
        case And(args):
            return And(tuple(substitute(a, env) for a in args))
        case Or(args):
            return Or(tuple(substitute(a, env) for a in args))
        case Implies(lhs, rhs):
            return Implies(substitute(lhs, env), substitute(rhs, env))
        case Iff(lhs, rhs):
            return Iff(substitute(lhs, env), substitute(rhs, env))
        case Cmp(op, lhs, rhs):
            return Cmp(op, substitute(lhs, env), substitute(rhs, env))
        case Arith(op, args):
            return Arith(op, tuple(substitute(a, env) for a in args))
        case In(arg, values):
            return In(substitute(arg, env), values)
        case _:
            assert_never(e)


def free_vars(e: Expr) -> frozenset[str]:
    match e:
        case BoolLit() | IntLit() | RealLit() | EnumLit():
            return frozenset()
        case Var(name):
            return frozenset({name})
        case Not(arg) | In(arg, _):
            return free_vars(arg)
        case And(args) | Or(args) | Arith(_, args):
            return frozenset().union(*(free_vars(a) for a in args))
        case Implies(lhs, rhs) | Iff(lhs, rhs) | Cmp(_, lhs, rhs):
            return free_vars(lhs) | free_vars(rhs)
        case _:
            assert_never(e)


TRUE, FALSE = BoolLit(True), BoolLit(False)


def _is_lit(e: Expr) -> bool:
    return isinstance(e, BoolLit | IntLit | RealLit | EnumLit)


def _fold(e: Expr) -> Expr:
    """Evaluate a closed node to its literal; leave anything else as it is."""
    return evaluate(e, {}).value_or(e) if not free_vars(e) else e


def _junction(args: tuple[Expr, ...], unit: BoolLit, zero: BoolLit, build: type[And] | type[Or]) -> Expr:
    flat: list[Expr] = []
    for a in args:
        flat.extend(a.args if isinstance(a, build) else (a,))
    if zero in flat:
        return zero
    kept = tuple(dict.fromkeys(a for a in flat if a != unit))  # drop units and duplicates, keep order
    return unit if not kept else kept[0] if len(kept) == 1 else build(kept)


def _negate(e: Expr) -> Expr:
    match e:
        case BoolLit(v):
            return BoolLit(not v)
        case Not(arg):
            return arg
        case _:
            return Not(e)


def simplify(e: Expr) -> Expr:
    """An equivalent expression with constants folded and Boolean units, zeros and duplicates removed."""
    match e:
        case BoolLit() | IntLit() | RealLit() | EnumLit() | Var():
            return e
        case Not(arg):
            return _negate(simplify(arg))
        case And(args):
            return _junction(tuple(simplify(a) for a in args), TRUE, FALSE, And)
        case Or(args):
            return _junction(tuple(simplify(a) for a in args), FALSE, TRUE, Or)
        case Implies(lhs, rhs):
            a, b = simplify(lhs), simplify(rhs)
            if a == TRUE:
                return b
            if b == TRUE or a in (FALSE, b):
                return TRUE
            return _negate(a) if b == FALSE else Implies(a, b)
        case Iff(lhs, rhs):
            a, b = simplify(lhs), simplify(rhs)
            if a == b:
                return TRUE
            for x, y in ((a, b), (b, a)):
                if x == TRUE:
                    return y
                if x == FALSE:
                    return _negate(y)
            return Iff(a, b)
        case Cmp(op, lhs, rhs):
            a, b = simplify(lhs), simplify(rhs)
            if a == b and op in ("eq", "le", "ge"):
                return TRUE
            if a == b and op in ("ne", "lt", "gt"):
                return FALSE
            return _fold(Cmp(op, a, b))
        case Arith(op, args):
            return _fold(Arith(op, tuple(simplify(a) for a in args)))
        case In(arg, values):
            return _fold(In(simplify(arg), values))
        case _:
            assert_never(e)
```

```python
"""Z3 as a compile target. The only module that imports z3.

`compile` builds one Z3 context per policy, so enum names never clash across policies. `check` makes a fresh solver
for every call and returns plain values (models as literals, unsat cores as labels), so callers stay pure: the same
inputs always give the same answer.
"""
from __future__ import annotations

from collections.abc import Callable, Mapping, Sequence
from dataclasses import dataclass
from fractions import Fraction
from functools import reduce
from typing import assert_never, cast

import z3

from policyproof.core.render import smt_name
from policyproof.core.semantics import rule_expr
from policyproof.core.syntax import (
    And,
    Arith,
    BoolLit,
    BoolSort,
    CheckedPolicy,
    Cmp,
    EnumLit,
    EnumSort,
    Expr,
    Iff,
    Implies,
    In,
    IntLit,
    IntSort,
    Lit,
    Not,
    Or,
    RealLit,
    RealSort,
    Rule,
    Sort,
    Var,
)
from policyproof.core.typecheck import signature

# ---- labels for unsat cores


@dataclass(frozen=True, slots=True)
class RuleLabel:
    id: str


@dataclass(frozen=True, slots=True)
class FactLabel:
    var: str
    value: Lit


@dataclass(frozen=True, slots=True)
class ExtraLabel:
    name: str


type Label = RuleLabel | FactLabel | ExtraLabel

# ---- results

type Model = Mapping[str, Lit]


@dataclass(frozen=True, slots=True)
class Sat:
    model: Model


@dataclass(frozen=True, slots=True)
class Unsat:
    core: frozenset[Label]


@dataclass(frozen=True, slots=True)
class Unknown:
    reason: str


type SatResult = Sat | Unsat | Unknown

# ---- compilation


@dataclass(frozen=True, slots=True)
class Compiled:
    policy: CheckedPolicy
    ctx: z3.Context
    variables: Mapping[str, z3.ExprRef]
    sorts: Mapping[str, Sort]
    values: Mapping[tuple[str, str], z3.ExprRef]
    rules: Mapping[str, z3.BoolRef]


def _declare(name: str, sort: Sort, ctx: z3.Context, enums: Mapping[str, z3.DatatypeSortRef]) -> z3.ExprRef:
    match sort:
        case BoolSort():
            return z3.Bool(name, ctx)
        case IntSort():
            return z3.Int(name, ctx)
        case RealSort():
            return z3.Real(name, ctx)
        case EnumSort(sname, _):
            return z3.Const(name, enums[sname])
        case _:
            assert_never(sort)


def compile(p: CheckedPolicy) -> Compiled:
    ctx = z3.Context()
    enums: dict[str, z3.DatatypeSortRef] = {}
    values: dict[tuple[str, str], z3.ExprRef] = {}
    for s in p.sorts:
        zsort, consts = z3.EnumSort(s.name, [smt_name(s.name, v) for v in s.values], ctx=ctx)
        enums[s.name] = zsort
        values |= {(s.name, v): c for v, c in zip(s.values, consts, strict=True)}
    sig = signature(p)
    variables = {n: _declare(n, s, ctx, enums) for n, s in sig.variables.items()}
    c = Compiled(p, ctx, variables, dict(sig.variables), values, {})
    return Compiled(p, ctx, variables, dict(sig.variables), values, {r.id: rule_formula(c, r) for r in p.rules})


def rule_formula(c: Compiled, r: Rule) -> z3.BoolRef:
    return _bool(to_z3(c, rule_expr(r)))


def to_z3(c: Compiled, e: Expr) -> z3.ExprRef:
    match e:
        case BoolLit(v):
            return z3.BoolVal(v, c.ctx)
        case IntLit(v):
            return z3.IntVal(v, c.ctx)
        case RealLit(v):
            return z3.RatVal(v.numerator, v.denominator, c.ctx)
        case EnumLit(sort, value):
            return c.values[(sort, value)]
        case Var(name):
            return c.variables[name]
        case Not(arg):
            return z3.Not(to_z3(c, arg), c.ctx)
        case And(args):
            return z3.And(*[to_z3(c, a) for a in args], c.ctx)
        case Or(args):
            return z3.Or(*[to_z3(c, a) for a in args], c.ctx)
        case Implies(lhs, rhs):
            return z3.Implies(to_z3(c, lhs), to_z3(c, rhs), c.ctx)
        case Iff(lhs, rhs):
            return _eq(to_z3(c, lhs), to_z3(c, rhs))
        case Cmp("eq", lhs, rhs):
            return _eq(to_z3(c, lhs), to_z3(c, rhs))
        case Cmp("ne", lhs, rhs):
            return z3.Not(_eq(to_z3(c, lhs), to_z3(c, rhs)), c.ctx)
        case Cmp(op, lhs, rhs):
            return ORDER[op](_arith(to_z3(c, lhs)), _arith(to_z3(c, rhs)))
        case Arith(op, args):
            return reduce(ARITH[op], [_arith(to_z3(c, a)) for a in args])
        case In(arg, values):
            x = to_z3(c, arg)
            return z3.Or(*[_eq(x, to_z3(c, v)) for v in values], c.ctx)
        case _:
            assert_never(e)


def _eq(a: z3.ExprRef, b: z3.ExprRef) -> z3.BoolRef:
    return cast(z3.BoolRef, a == b)  # z3 overloads == to build a term, which checkers read as bool


def _bool(x: z3.ExprRef) -> z3.BoolRef:
    return cast(z3.BoolRef, x)  # rule bodies of well-typed policies are Boolean terms


def _arith(x: z3.ExprRef) -> z3.ArithRef:
    return cast(z3.ArithRef, x)  # only well-typed policies are compiled: these operands are Int or Real terms


ORDER: dict[str, Callable[[z3.ArithRef, z3.ArithRef], z3.BoolRef]] = {
    "lt": lambda x, y: x < y, "le": lambda x, y: x <= y, "gt": lambda x, y: x > y, "ge": lambda x, y: x >= y}
ARITH: dict[str, Callable[[z3.ArithRef, z3.ArithRef], z3.ArithRef]] = {
    "add": lambda x, y: x + y, "sub": lambda x, y: x - y, "mul": lambda x, y: x * y}


def _to_lit(c: Compiled, sort: Sort, v: z3.ExprRef) -> Lit:
    match sort:
        case BoolSort():
            return BoolLit(z3.is_true(v))
        case IntSort():
            return IntLit(v.as_long())  # ty: ignore[unresolved-attribute] - an IntNumRef once evaluated
        case RealSort():
            return RealLit(Fraction(v.as_fraction()))  # ty: ignore[unresolved-attribute] - a RatNumRef
        case EnumSort(sname, _):
            return EnumLit(sname, str(v).removeprefix(f"{sname}."))
        case _:
            assert_never(sort)


def ground(c: Compiled, e: Expr, sort: Sort, env: Mapping[str, Lit]) -> Lit:
    """Z3's value of `e` with every variable replaced by its value in `env` (which must bind all of them)."""
    pairs = [(c.variables[n], to_z3(c, v)) for n, v in env.items() if n in c.variables]
    term = z3.substitute(to_z3(c, e), *pairs) if pairs else to_z3(c, e)
    return _to_lit(c, sort, z3.simplify(term))


def check(c: Compiled, assertions: Sequence[tuple[Label, Expr]], *, rules: bool = True) -> SatResult:
    """Satisfiability of the policy's rules (unless `rules=False`) together with `assertions`, each tracked by its
    label so an unsat core can be named."""
    s = z3.Solver(ctx=c.ctx)
    labels: list[Label] = []
    tracked = [*((RuleLabel(rid), f) for rid, f in c.rules.items() if rules),
               *((label, to_z3(c, e)) for label, e in assertions)]
    for i, (label, formula) in enumerate(tracked):
        labels.append(label)
        s.assert_and_track(formula, z3.Bool(f"__track_{i}", c.ctx))
    match s.check():
        case z3.sat:
            m = s.model()
            return Sat({n: _to_lit(c, c.sorts[n], m.eval(v, model_completion=True)) for n, v in c.variables.items()})
        case z3.unsat:
            return Unsat(frozenset(labels[int(str(t).removeprefix("__track_"))] for t in s.unsat_core()))
        case _:
            return Unknown(s.reason_unknown())


def fact(var: str, value: Lit) -> tuple[Label, Expr]:
    """The tracked assertion `var == value`."""
    return FactLabel(var, value), Cmp("eq", Var(var), value)
```

```python
"""Classifying a claim against a policy: proven, refuted, contingent, or the premises are inconsistent."""
from __future__ import annotations

from collections.abc import Mapping, Sequence
from dataclasses import dataclass
from typing import assert_never

from policyproof.core.solver import (
    Compiled,
    ExtraLabel,
    Label,
    Model,
    Sat,
    Unknown,
    Unsat,
    check,
    fact,
)
from policyproof.core.syntax import Expr, Iff, Lit, Not


@dataclass(frozen=True, slots=True)
class Proven:
    """Every world allowed by the rules and premises makes the claim true. `core` names what the proof used."""

    core: frozenset[Label]


@dataclass(frozen=True, slots=True)
class Refuted:
    """No such world makes the claim true. `core` names what rules it out."""

    core: frozenset[Label]


@dataclass(frozen=True, slots=True)
class Contingent:
    """Some worlds make it true and some false: a witness of each."""

    when_true: Model
    when_false: Model


@dataclass(frozen=True, slots=True)
class Inconsistent:
    """The rules and premises contradict each other, so nothing can be concluded."""

    core: frozenset[Label]


@dataclass(frozen=True, slots=True)
class Undetermined:
    """The solver gave up (for example on non-linear arithmetic)."""

    reason: str


type Verdict = Proven | Refuted | Contingent | Inconsistent | Undetermined

CLAIM, NOT_CLAIM = ExtraLabel("claim"), ExtraLabel("negated claim")


def premises(given: Mapping[str, Lit] | None = None, exprs: Sequence[Expr] = ()) -> list[tuple[Label, Expr]]:
    """Tracked assertions: one `var == value` per given fact, then each expression as `premise[i]`."""
    return [*(fact(n, v) for n, v in (given or {}).items()),
            *((ExtraLabel(f"premise[{i}]"), e) for i, e in enumerate(exprs))]


def classify(c: Compiled, claim: Expr, assertions: Sequence[tuple[Label, Expr]] = (), *, rules: bool = True
             ) -> Verdict:
    match check(c, assertions, rules=rules):
        case Unsat(core):
            return Inconsistent(core)
        case Unknown(reason):
            return Undetermined(reason)
        case Sat():
            pass
        case other:
            assert_never(other)
    negated = check(c, [*assertions, (NOT_CLAIM, Not(claim))], rules=rules)
    if isinstance(negated, Unsat):
        return Proven(negated.core - {NOT_CLAIM})
    affirmed = check(c, [*assertions, (CLAIM, claim)], rules=rules)
    if isinstance(affirmed, Unsat):
        return Refuted(affirmed.core - {CLAIM})
    if isinstance(negated, Sat) and isinstance(affirmed, Sat):
        return Contingent(affirmed.model, negated.model)
    unknown = negated if isinstance(negated, Unknown) else affirmed
    return Undetermined(unknown.reason if isinstance(unknown, Unknown) else "unknown")


def entails(c: Compiled, given: Sequence[Expr], conclusion: Expr, *, rules: bool = True) -> bool:
    """`given` (with the rules, unless `rules=False`) proves `conclusion`, and `given` is consistent."""
    return isinstance(classify(c, conclusion, premises(exprs=given), rules=rules), Proven)


def equivalent(c: Compiled, a: Expr, b: Expr) -> bool:
    """`a` and `b` mean the same in every world, regardless of the policy's rules."""
    return isinstance(check(c, [(NOT_CLAIM, Not(Iff(a, b)))], rules=False), Unsat)
```

```python
"""A brute-force oracle: enumerate every world of the finite variables (p, q, r, c) and judge a claim directly."""
from itertools import product

from strategies import COLOR, FINITE

from policyproof.core.semantics import evaluate, rule_expr
from policyproof.core.syntax import BoolLit, EnumLit, Expr, Lit, Rule

WORLDS: list[dict[str, Lit]] = [
    {"p": BoolLit(p), "q": BoolLit(q), "r": BoolLit(r), "c": EnumLit("Color", c)}
    for p, q, r, c in product((False, True), (False, True), (False, True), COLOR.values)
]
assert len(WORLDS) == 24 and all(set(w) == set(FINITE) for w in WORLDS)


def holds(e: Expr, world: dict[str, Lit]) -> bool:
    return evaluate(e, world).unwrap() == BoolLit(True)


def judge(rules: tuple[Rule, ...], given: dict[str, Lit], claim: Expr) -> str:
    """'proven' | 'refuted' | 'contingent' | 'inconsistent', by checking every world."""
    allowed = [w for w in WORLDS if all(holds(rule_expr(r), w) for r in rules)
               and all(w[k] == v for k, v in given.items())]
    if not allowed:
        return "inconsistent"
    truths = {holds(claim, w) for w in allowed}
    return "proven" if truths == {True} else "refuted" if truths == {False} else "contingent"
```

```python
def totality(c: Compiled, inputs: frozenset[str]) -> SatResult:
    """`Sat(witness)` when some values of `inputs` that meet the rules about inputs alone leave no values of the
    other variables that meet every rule: the policy has no answer for that case. `Unsat` when it always has one."""
    domain = [r for r in c.policy.rules if free_vars(rule_expr(r)) <= inputs]
    rest = [r for r in c.policy.rules if r not in domain]
    others = [v for n, v in c.variables.items() if n not in inputs]
    no_answer = z3.Not(z3.And(*[c.rules[r.id] for r in rest], c.ctx), c.ctx)
    s = z3.Solver(ctx=c.ctx)
    s.add(*[c.rules[r.id] for r in domain])
    s.add(z3.ForAll(others, no_answer) if others else no_answer)
    match s.check():
        case z3.sat:
            m = s.model()
            witness = {n: _to_lit(c, c.sorts[n], m.eval(c.variables[n], model_completion=True)) for n in sorted(inputs)}
            return Sat(witness)
        case z3.unsat:
            return Unsat(frozenset())
        case _:
            return Unknown(s.reason_unknown())
```

```python
"""Validation: is the policy sound enough to decide with? Run it before publishing; `gate` is the release check."""

import re
from dataclasses import dataclass
from difflib import SequenceMatcher
from itertools import combinations
from typing import Literal, assert_never

from returns.result import Failure, Result, Success

from policyproof.core.semantics import free_vars, rule_expr
from policyproof.core.solver import Compiled, Model, RuleLabel, Sat, Unknown, Unsat, check, fact, totality
from policyproof.core.syntax import (
    Ask,
    BoolLit,
    BoolSort,
    Constraint,
    Define,
    Derived,
    EnumLit,
    EnumSort,
    Lit,
    Rule,
    System,
    When,
)


@dataclass(frozen=True, slots=True)
class Conflict:
    """These rules contradict each other outright: no world satisfies them."""

    rules: tuple[str, ...]


@dataclass(frozen=True, slots=True)
class NotTotal:
    """For these input values the rules leave no possible answer."""

    witness: Model


@dataclass(frozen=True, slots=True)
class ImpossibleInput:
    """The rules rule out a value that a system or the customer could supply."""

    var: str
    value: Lit


@dataclass(frozen=True, slots=True)
class UnreachableOutcome:
    outcome: str


@dataclass(frozen=True, slots=True)
class SolverGaveUp:
    check: str
    reason: str


@dataclass(frozen=True, slots=True)
class UnusedVariable:
    var: str


@dataclass(frozen=True, slots=True)
class NearDuplicate:
    a: str
    b: str


@dataclass(frozen=True, slots=True)
class DisjointGroups:
    """The rules fall into groups that share no variable: often one idea under two names."""

    groups: tuple[tuple[str, ...], ...]


@dataclass(frozen=True, slots=True)
class OverlappingOutcomes:
    """Both outcomes can hold at once, so the decision depends on their order (the earlier one wins)."""

    first: str
    second: str


@dataclass(frozen=True, slots=True)
class ConstraintRule:
    rule: str


@dataclass(frozen=True, slots=True)
class DefinitionToReview:
    rule: str


type Finding = (Conflict | NotTotal | ImpossibleInput | UnreachableOutcome | SolverGaveUp | UnusedVariable
                | NearDuplicate | DisjointGroups | OverlappingOutcomes | ConstraintRule | DefinitionToReview)
type Severity = Literal["error", "warning", "review"]
SEVERITY_ORDER: dict[Severity, int] = {"error": 0, "warning": 1, "review": 2}


def severity(f: Finding) -> Severity:
    match f:
        case Conflict() | NotTotal() | ImpossibleInput() | UnreachableOutcome() | SolverGaveUp():
            return "error"
        case UnusedVariable() | NearDuplicate() | DisjointGroups():
            return "warning"
        case OverlappingOutcomes() | ConstraintRule() | DefinitionToReview():
            return "review"
        case _:
            assert_never(f)


def _rule_vars(r: Rule) -> frozenset[str]:
    return free_vars(rule_expr(r))


def _structural(c: Compiled) -> list[Finding]:
    p = c.policy
    found: list[Finding] = []
    for r in p.rules:
        match r:
            case Constraint():
                found.append(ConstraintRule(r.id))
            case Define():
                found.append(DefinitionToReview(r.id))
            case When():
                pass
            case _:
                assert_never(r)
    used = frozenset().union(*(_rule_vars(r) for r in p.rules), *({v for v, _ in o.assignment} for o in p.outcomes))
    found += [UnusedVariable(v.name) for v in p.variables if v.name not in used]
    names = [v.name for v in p.variables]
    found += [NearDuplicate(a, b) for a, b in combinations(names, 2) if _near(a, b)]
    groups = _groups(p.rules)
    if len(groups) > 1:
        found.append(DisjointGroups(groups))
    return found


STOP_WORDS = {"is", "has", "was", "the", "a", "an", "of", "for", "to", "be"}


def _tokens(name: str) -> frozenset[str]:
    words = re.findall(r"[A-Z]?[a-z0-9]+|[A-Z]+(?![a-z])", name)
    return frozenset(w.lower() for w in words) - STOP_WORDS


def _near(a: str, b: str) -> bool:
    return _tokens(a) == _tokens(b) or SequenceMatcher(None, a.lower(), b.lower()).ratio() >= 0.85


def _groups(rules: tuple[Rule, ...]) -> tuple[tuple[str, ...], ...]:
    """Rules connected by shared variables, each group in policy order."""
    groups: list[tuple[set[str], list[str]]] = []
    for r in rules:
        names = set(_rule_vars(r))
        touching = [g for g in groups if g[0] & names] if names else []
        merged = (names.union(*(g[0] for g in touching)), [rid for g in touching for rid in g[1]] + [r.id])
        groups = [g for g in groups if g not in touching] + [merged]
    order = {r.id: i for i, r in enumerate(rules)}
    return tuple(sorted((tuple(sorted(ids, key=order.__getitem__)) for _, ids in groups), key=lambda g: order[g[0]]))


def _finite_values(v_sort: BoolSort | EnumSort) -> tuple[Lit, ...]:
    match v_sort:
        case BoolSort():
            return (BoolLit(False), BoolLit(True))
        case EnumSort(name, values):
            return tuple(EnumLit(name, x) for x in values)
        case _:
            assert_never(v_sort)


def _logical(c: Compiled) -> list[Finding]:
    p = c.policy
    found: list[Finding] = []
    inputs = frozenset(v.name for v in p.variables if isinstance(v.role, System | Ask))
    match totality(c, inputs):
        case Sat(witness):
            found.append(NotTotal(witness))
        case Unknown(reason):
            found.append(SolverGaveUp("totality", reason))
        case Unsat():
            pass
        case other:
            assert_never(other)
    for v in p.variables:
        if isinstance(v.role, Derived) or not isinstance(v.sort, BoolSort | EnumSort):
            continue
        found += [ImpossibleInput(v.name, x) for x in _finite_values(v.sort)
                  if isinstance(check(c, [fact(v.name, x)]), Unsat)]
    assignments = {o.name: [fact(var, value) for var, value in o.assignment] for o in p.outcomes}
    found += [UnreachableOutcome(name) for name, a in assignments.items() if isinstance(check(c, a), Unsat)]
    found += [OverlappingOutcomes(a, b) for a, b in combinations(assignments, 2)
              if isinstance(check(c, assignments[a] + assignments[b]), Sat)]
    return found


def validate(c: Compiled) -> tuple[Finding, ...]:
    """Every finding, errors first. Logical checks are skipped when the rules contradict each other outright."""
    order = {r.id: i for i, r in enumerate(c.policy.rules)}
    match check(c, []):
        case Unsat(core):
            ids = sorted((label.id for label in core if isinstance(label, RuleLabel)), key=order.__getitem__)
            found: list[Finding] = [Conflict(tuple(ids))]
        case Unknown(reason):
            found = [SolverGaveUp("consistency", reason)]
        case Sat():
            found = _logical(c)
        case other:
            assert_never(other)
    return tuple(sorted(found + _structural(c), key=lambda f: SEVERITY_ORDER[severity(f)]))


def gate(c: Compiled) -> Result[Compiled, tuple[Finding, ...]]:
    """Success when there are no errors; otherwise every finding."""
    report = validate(c)
    return Failure(report) if any(severity(f) == "error" for f in report) else Success(c)
```

```python
"""Facts with provenance, and how facts from different sources combine.

A system of record beats the customer's answer to a question, which beats something the customer only mentioned in
passing. `merge` keeps, for each variable, every fact at the highest rank seen. Conflicting facts at the same rank
are both kept, so a contradiction stays visible to `decide` instead of being resolved silently. `merge` is a
semilattice join: associative, commutative and idempotent (law L9).
"""
from __future__ import annotations

from collections.abc import Mapping
from dataclasses import dataclass
from functools import reduce
from typing import assert_never

from policyproof.core.syntax import Lit


@dataclass(frozen=True, slots=True)
class FromSystem:
    source: str


@dataclass(frozen=True, slots=True)
class Answered:
    question: str
    quote: str


@dataclass(frozen=True, slots=True)
class Volunteered:
    quote: str


type Provenance = FromSystem | Answered | Volunteered


@dataclass(frozen=True, slots=True)
class Fact:
    var: str
    value: Lit
    provenance: Provenance


type Facts = Mapping[str, frozenset[Fact]]


def rank(p: Provenance) -> int:
    match p:
        case FromSystem():
            return 3
        case Answered():
            return 2
        case Volunteered():
            return 1
        case _:
            assert_never(p)


def merge(a: Facts, b: Facts) -> Facts:
    out: dict[str, frozenset[Fact]] = {}
    for var in a.keys() | b.keys():
        both = a.get(var, frozenset()) | b.get(var, frozenset())
        top = max(rank(f.provenance) for f in both)
        out[var] = frozenset(f for f in both if rank(f.provenance) == top)
    return out


def facts(*fs: Fact) -> Facts:
    """Facts from individual statements, merged."""
    return reduce(merge, ({f.var: frozenset({f})} for f in fs), {})


def all_facts(fs: Facts) -> tuple[Fact, ...]:
    """Every fact, in a stable order (by variable name, then value and provenance)."""
    return tuple(sorted((f for group in fs.values() for f in group), key=repr))
```

```python
"""Deciding: the first outcome the facts prove, or the one question that settles it.

1. The rules and all facts must be consistent, or the result is a `Contradiction` naming the rules and facts.
2. The first outcome (in policy order) proven from the firm facts is `Decided`. Firm facts are the ones that come from
   a system or answer a question, plus volunteered facts about variables that don't need confirmation.
3. If an outcome is proven only with a volunteered fact, that fact is confirmed first: `NeedInfo(reason="confirm")`.
4. Otherwise the policy asks about the askable variable whose answers decide the most outcomes (the what-if table),
   ties broken by policy order. With nothing left to ask: `Escalate`.
"""

from collections.abc import Iterable, Sequence
from dataclasses import dataclass
from typing import Literal, assert_never

from policyproof.core.facts import Answered, Fact, Facts, Volunteered, all_facts
from policyproof.core.prove import Proven, classify
from policyproof.core.semantics import free_vars, rule_expr
from policyproof.core.solver import Compiled, FactLabel, Label, RuleLabel, Sat, Unknown, Unsat, check, fact
from policyproof.core.syntax import (
    And,
    Ask,
    BoolLit,
    BoolSort,
    Cmp,
    EnumLit,
    EnumSort,
    Expr,
    Lit,
    Outcome,
    Var,
    Variable,
)

type Reason = Literal["missing", "confirm", "unclear"]


@dataclass(frozen=True, slots=True)
class Decided:
    outcome: str
    rules: tuple[str, ...]
    facts_used: tuple[Fact, ...]


@dataclass(frozen=True, slots=True)
class NeedInfo:
    var: str
    question: str
    reason: Reason
    what_if: tuple[tuple[Lit, str | None], ...]  # each possible answer, and the outcome it would prove


@dataclass(frozen=True, slots=True)
class Contradiction:
    rules: tuple[str, ...]
    facts: tuple[Fact, ...]


@dataclass(frozen=True, slots=True)
class Escalate:

type Decision = Decided | NeedInfo | Contradiction | Escalate


def outcome_expr(o: Outcome) -> Expr:
    parts = tuple(Cmp("eq", Var(v), lit) for v, lit in o.assignment)
    return parts[0] if len(parts) == 1 else And(parts)


def fact_assertions(fs: Iterable[Fact]) -> list[tuple[Label, Expr]]:
    """One tracked `var == value` per distinct fact."""
    return list(dict.fromkeys(fact(f.var, f.value) for f in fs))


def _rule_ids(c: Compiled, core: frozenset[Label]) -> tuple[str, ...]:
    return tuple(r.id for r in c.policy.rules if RuleLabel(r.id) in core)


def _facts_in(core: frozenset[Label], fs: Sequence[Fact]) -> tuple[Fact, ...]:
    return tuple(f for f in fs if FactLabel(f.var, f.value) in core)


def _variable(c: Compiled, name: str) -> Variable:
    return next(v for v in c.policy.variables if v.name == name)


def _needs_confirmation(c: Compiled, f: Fact) -> bool:
    role = _variable(c, f.var).role
    return isinstance(f.provenance, Volunteered) and isinstance(role, Ask) and role.confirm_volunteered


def _first_proven(c: Compiled, fs: Sequence[Fact]) -> tuple[Outcome, frozenset[Label]] | None:
    for o in c.policy.outcomes:
        verdict = classify(c, outcome_expr(o), fact_assertions(fs))
        if isinstance(verdict, Proven):
            return o, verdict.core
    return None


def _answers(v: Variable) -> tuple[Lit, ...]:
    match v.sort:
        case BoolSort():
            return (BoolLit(True), BoolLit(False))
        case EnumSort(name, values):
            return tuple(EnumLit(name, x) for x in values)
        case _:
            return ()  # Int and Real answers can't be enumerated


def what_if(c: Compiled, firm: Sequence[Fact], var: str) -> tuple[tuple[Lit, str | None], ...]:
    out: list[tuple[Lit, str | None]] = []
    for value in _answers(_variable(c, var)):
        hit = _first_proven(c, [*firm, Fact(var, value, Answered("", ""))])
        out.append((value, hit[0].name if hit else None))
    return tuple(out)


def _question(c: Compiled, firm: Sequence[Fact], every: Sequence[Fact], unclear: frozenset[str]) -> Decision:
    known = {f.var for f in firm}
    used = frozenset().union(*(free_vars(rule_expr(r)) for r in c.policy.rules))
    candidates = [v for v in c.policy.variables
                  if isinstance(v.role, Ask) and v.name not in known and v.name in used]
    if not candidates:
        return Escalate("no outcome can be proven and there is nothing left to ask")
    tables = [what_if(c, firm, v.name) for v in candidates]
    scores = [sum(o is not None for _, o in t) for t in tables]
    best = max(range(len(candidates)), key=lambda i: (scores[i], -i))
    v, role = candidates[best], candidates[best].role
    assert isinstance(role, Ask)
    reason: Reason = ("unclear" if v.name in unclear
                      else "confirm" if any(f.var == v.name for f in every) else "missing")
    return NeedInfo(v.name, role.question, reason, tables[best])


def firm_facts(c: Compiled, fs: Facts) -> tuple[Fact, ...]:
    """The facts a decision may rest on: all of them except volunteered ones that still need confirming."""
    return tuple(f for f in all_facts(fs) if not _needs_confirmation(c, f))


def decide(c: Compiled, fs: Facts, *, unclear: frozenset[str] = frozenset()) -> Decision:
    """`unclear`: variables whose last answer couldn't be read, so the question is asked again."""
    every = all_facts(fs)
    match check(c, fact_assertions(every)):
        case Unsat(core):
            return Contradiction(_rule_ids(c, core), _facts_in(core, every))
        case Unknown(reason):
            return Escalate(f"the solver gave up: {reason}")
        case Sat():
            pass
        case other:
            assert_never(other)
    firm = firm_facts(c, fs)
    hit = _first_proven(c, firm)
    if hit:
        o, core = hit
        return Decided(o.name, _rule_ids(c, core), _facts_in(core, firm))
    hit = _first_proven(c, every)
    if hit:
        pending = [f for f in _facts_in(hit[1], every) if _needs_confirmation(c, f)]
        if pending:
            var = pending[0].var
            role = _variable(c, var).role
            assert isinstance(role, Ask)
            return NeedInfo(var, role.question, "confirm", what_if(c, firm, var))
    return _question(c, firm, every, unclear)
```

```python
"""Explanations of a decision: the facts and where they came from, the rule steps, and a runnable SMT-LIB proof."""
from __future__ import annotations

from dataclasses import dataclass
from typing import assert_never

from policyproof.core.decide import Contradiction, Decided, Decision, Escalate, NeedInfo, outcome_expr
from policyproof.core.facts import Fact, Facts, all_facts
from policyproof.core.render import pretty, smt_declarations, to_smtlib
from policyproof.core.semantics import rule_expr
from policyproof.core.solver import Compiled
from policyproof.core.syntax import Cmp, Constraint, Define, Expr, Not, Rule, Var, When
from policyproof.core.typecheck import signature


@dataclass(frozen=True, slots=True)
class Step:
    rule: str
    premise: str
    conclusion: str
    explain: str | None


@dataclass(frozen=True, slots=True)
class Trace:
    facts: tuple[Fact, ...]
    steps: tuple[Step, ...]
    smtlib: str  # run it with any SMT solver: `unsat` means the outcome is proven
    expected: str  # "unsat", "sat", or "" when there is nothing to run


def step(r: Rule) -> Step:
    match r:
        case When(rid, when, then, _, explain):
            return Step(rid, pretty(when), pretty(then), explain)
        case Define(rid, var, as_, _, explain):
            return Step(rid, pretty(as_), f"{var} (and only then)", explain)
        case Constraint(rid, expr, _, explain):
            return Step(rid, "", pretty(expr), explain)
        case _:
            assert_never(r)


def script(c: Compiled, rule_ids: tuple[str, ...], fs: tuple[Fact, ...], goal: Expr | None) -> str:
    """SMT-LIB: the declarations, the named rules, the facts, and `goal` negated; then `(check-sat)`."""
    lines = [smt_declarations(signature(c.policy))]
    lines += [f"(assert (! {to_smtlib(rule_expr(r))} :named |{r.id}|))" for r in c.policy.rules if r.id in rule_ids]
    lines += [f"(assert {to_smtlib(Cmp('eq', Var(f.var), f.value))})" for f in dict.fromkeys(fs)]
    if goal is not None:
        lines.append(f"(assert {to_smtlib(Not(goal))})")
    return "\n".join([*lines, "(check-sat)"])


def explain(c: Compiled, d: Decision, fs: Facts) -> Trace:
    every = all_facts(fs)
    all_ids = tuple(r.id for r in c.policy.rules)
    match d:
        case Decided(outcome, rules, used):
            goal = outcome_expr(next(o for o in c.policy.outcomes if o.name == outcome))
            steps = tuple(step(r) for r in c.policy.rules if r.id in rules)
            return Trace(used, steps, script(c, rules, used, goal), "unsat")
        case NeedInfo():
            return Trace(every, (), script(c, all_ids, every, None), "sat")
        case Contradiction(rules, facts):
            steps = tuple(step(r) for r in c.policy.rules if r.id in rules)
            return Trace(facts, steps, script(c, rules, facts, None), "unsat")
        case Escalate():
            return Trace(every, (), "", "")
        case _:
            assert_never(d)
```

```python
"""The answer check: is everything a reply claims proven by the policy and the facts, and does the reply do what the
decision requires? Claims arrive already translated (by a translator in `policyproof.effects`); this module only
judges them.

A reply rule is a plain function from the check's input to the problems it finds. The built-in rules are generic;
domain rules (forbidden offers, required source mentions, allowed flight numbers) are made with `forbid`,
`require_mention` and `only_entities`.
"""
from __future__ import annotations

import re
from collections.abc import Callable, Sequence
from dataclasses import dataclass
from typing import Literal, assert_never

from policyproof.core.decide import Decided, Decision, NeedInfo, fact_assertions, firm_facts, outcome_expr
from policyproof.core.facts import Facts
from policyproof.core.prove import Contingent, Inconsistent, Proven, Refuted, Undetermined, classify, entails
from policyproof.core.solver import Compiled
from policyproof.core.syntax import Expr

type ClaimStatus = Literal["proven", "contradicts", "not_proven", "inconsistent", "ungrounded"]


@dataclass(frozen=True, slots=True)
class Claim:
    expr: Expr
    quote: str  # the words in the reply the claim was read from


@dataclass(frozen=True, slots=True)
class ClaimResult:
    claim: Claim
    status: ClaimStatus


@dataclass(frozen=True, slots=True)
class Problem:
    rule: str
    message: str


@dataclass(frozen=True, slots=True)
class CheckInput:
    compiled: Compiled
    decision: Decision
    facts: Facts
    reply: str
    claims: tuple[ClaimResult, ...]


@dataclass(frozen=True, slots=True)
class CheckResult:
    passed: bool
    claims: tuple[ClaimResult, ...]
    problems: tuple[Problem, ...]


type ReplyRule = Callable[[CheckInput], tuple[Problem, ...]]


def normalize(text: str) -> str:
    return re.sub(r"[^a-z0-9]+", " ", text.lower()).strip()


def judge_claims(c: Compiled, fs: Facts, reply: str, claims: Sequence[Claim]) -> tuple[ClaimResult, ...]:
    """Each claim's status against the rules and the firm facts. A claim whose quote isn't in the reply is
    'ungrounded': the translator invented it, so it is reported but not held against the reply."""
    text, given = normalize(reply), fact_assertions(firm_facts(c, fs))

    def status(claim: Claim) -> ClaimStatus:
        if not claim.quote.strip() or normalize(claim.quote) not in text:
            return "ungrounded"
        verdict = classify(c, claim.expr, given)
        match verdict:
            case Proven():
                return "proven"
            case Refuted():
                return "contradicts"
            case Contingent() | Undetermined():
                return "not_proven"
            case Inconsistent():
                return "inconsistent"
            case _:
                assert_never(verdict)

    return tuple(ClaimResult(claim, status(claim)) for claim in claims)


# ---- built-in rules


def claims_hold(i: CheckInput) -> tuple[Problem, ...]:
    words = {"contradicts": "contradicts the policy and the facts",
             "not_proven": "is not proven: nothing in the decision supports it",
             "inconsistent": "rests on facts that contradict each other"}
    return tuple(Problem("claims_hold", f'"{r.claim.quote}" {words[r.status]}.')
                 for r in i.claims if r.status in words)


def states_outcome(i: CheckInput) -> tuple[Problem, ...]:
    if not isinstance(i.decision, Decided):
        return ()
    name = i.decision.outcome
    goal = outcome_expr(next(o for o in i.compiled.policy.outcomes if o.name == name))
    if any(r.status == "proven" and entails(i.compiled, [r.claim.expr], goal) for r in i.claims):
        return ()
    return (Problem("states_outcome", f"The reply must clearly state the outcome ({name.replace('_', ' ')})."),)


def asks_open_question(i: CheckInput) -> tuple[Problem, ...]:
    """The answer is read against the exact question, so it must be asked word for word, and last."""
    if not isinstance(i.decision, NeedInfo):
        return ()
    question, text = normalize(i.decision.question), normalize(i.reply)
    if question not in text:
        return (Problem("asks_open_question", f'Ask the open question exactly as written: "{i.decision.question}"'),)
    if not text.endswith(question):
        return (Problem("asks_open_question", "The open question must be the last thing in the reply."),)
    return ()


def single_question(i: CheckInput) -> tuple[Problem, ...]:
    """A yes/no answer is only unambiguous if the question isn't "A, or B?"."""
    if not isinstance(i.decision, NeedInfo):
        return ()
    questions = re.findall(r"[^.?!]*\?", i.reply)
    if any(re.search(r"\bor\b", q, re.IGNORECASE) for q in questions):
        return (Problem("single_question", "Ask one yes/no question, not an either/or question."),)
    return ()


DEFAULT_RULES: tuple[ReplyRule, ...] = (claims_hold, states_outcome, asks_open_question, single_question)

# ---- rule builders for domain checks


def forbid(pattern: str, message: str) -> ReplyRule:
    """A problem whenever `pattern` occurs (case-insensitive), e.g. offers the policy never makes."""
    def rule(i: CheckInput) -> tuple[Problem, ...]:
        found = sorted({m.group(0).lower() for m in re.finditer(pattern, i.reply, re.IGNORECASE)})
        return (Problem("forbid", f"{message}: {', '.join(found)}"),) if found else ()
    return rule


def require_mention(pattern: str, message: str) -> ReplyRule:
    """Once decided, the reply must mention `pattern` (e.g. where the facts came from)."""
    def rule(i: CheckInput) -> tuple[Problem, ...]:
        decided = isinstance(i.decision, Decided)
        return (Problem("require_mention", message),) if decided and not re.search(pattern, i.reply, re.I) else ()
    return rule


def only_entities(pattern: str, allowed: frozenset[str], message: str) -> ReplyRule:
    """Every match of `pattern` must be in `allowed` (e.g. only flight numbers the schedule returned)."""
    def rule(i: CheckInput) -> tuple[Problem, ...]:
        extra = sorted(set(re.findall(pattern, i.reply)) - allowed)
        return (Problem("only_entities", f"{message}: {', '.join(extra)}"),) if extra else ()
    return rule


def check_reply(c: Compiled, decision: Decision, fs: Facts, reply: str, claims: Sequence[Claim],
                rules: Sequence[ReplyRule] = DEFAULT_RULES) -> CheckResult:
    judged = judge_claims(c, fs, reply, claims)
    i = CheckInput(c, decision, fs, reply, judged)
    problems = tuple(p for rule in rules for p in rule(i))
    return CheckResult(not problems, judged, problems)
```

```python
from conftest import load
```

```python
           ("said yes in passing", ("volunteered", True)), ("said no in passing", ("volunteered", False))]


def to_lit(sort: Sort, value: object) -> Lit:
    match sort:
        case BoolSort():
            return BoolLit(bool(value))
        case IntSort():
            return IntLit(int(value))  # ty: ignore[invalid-argument-type] - demo data are ints here
        case EnumSort(name, _):
            return EnumLit(name, str(value))
        case _:
            raise AssertionError(sort)

def demo():
    sys.path.insert(0, str(DEMO / "decision"))  # the demo's modules are flat: `core`, `bookings`
    core, bookings = importlib.import_module("core"), importlib.import_module("bookings")
    return core, bookings, core.Policy.load(DEMO / "policy")

@pytest.mark.parametrize("ref", ["K7PQ2M", "R3VN8D", "T4XB9R", "H2LW6C"])

    sorts = {v.name: v.sort for v in policy.variables}

    known = [Fact(n, to_lit(sorts[n], v), FromSystem("demo systems")) for n, v in system.items()]
```
