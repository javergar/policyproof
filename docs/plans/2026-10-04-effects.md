# policyproof milestone 2 (the effects layer): implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Read facts, answers and claims out of text with any LLM (through pydantic-ai) or Jev, and run a conversation
turn through two fail-closed pipelines: `read_turn` (a message into facts and a decision) and `guard_reply` (a draft
reply checked, rewritten once, or replaced by a fallback).

**Architecture:** Pure guards (`policyproof.guards`, the core only) check everything a reader returns. Readers sit
behind async Protocols (`effects.ports`) returning `Result`; consensus and the pipelines use only the ports. The
pydantic-ai implementations live in `effects.llm` (`[llm]`) and `effects.jev` (`[jev]`), the only modules that import
it. Laws E1 to E5 are Hypothesis properties.

**Tech Stack:** Python >= 3.13, uv, pydantic-ai-slim 2.54+ (Bedrock, TypeSafe), returns, z3-solver; ty, ruff, pytest,
Hypothesis, import-linter, jsonschema.

**Spec:** `docs/specs/2026-10-03-effects-design.md` (see its section "Refinements from prototyping the plan").

**Provenance:** every code block below ran on 2026-10-04 in a scratch copy, one commit per task, and each task's end
state was checked on its own (ruff, ty, import-linter, full suite). At the end: 215 tests pass, 4 import contracts are
kept, the CI-profile laws pass (1000 examples each), and the live tests pass on Bedrock Claude Haiku 4.5 (Jev: skipped,
no key). Diffs are against the previous task's end state.

## Review Focus

Inputs a person will meet that the spec doesn't name. Each has a test in the task that owns the code:

1. A model writes an enum value in another case (`"courier"`): accepted when unambiguous
   (`test_enum_values_match_in_any_case_when_unambiguous`, Task 2).
2. A quote with a curly apostrophe against a straight one in the message (`I’d` / `I'd`): they match
   (`test_quotes_match_across_straight_and_curly_apostrophes`, Task 2).
3. A variable named like a pydantic attribute (`model_config`, `schema`): the Jev reader still works

5. Jev asked to read a number answer: `Refused`, so `AgreeingAnswers` uses the other reader
   (`test_jev_refuses_number_answers_so_consensus_uses_the_other_reader`, Task 9).

```python
"""What readers return, before any guard has looked at it: plain values, unverified quotes, untyped expressions."""
from dataclasses import dataclass

from policyproof.core.facts import Evidence


@dataclass(frozen=True, slots=True)
class Said:
    """The message answers the question with `value`, in the words `quote`."""
    value: object
    quote: str


@dataclass(frozen=True, slots=True)
class Unclear:
    """The message tries to answer but can't be read as one value; the question is asked again."""
    reason: str


@dataclass(frozen=True, slots=True)
class NotAnswered:
    """The message doesn't answer the question (e.g. it asks something else)."""


type RawAnswer = Said | Unclear | NotAnswered


@dataclass(frozen=True, slots=True)
class RawFact:
    var: str
    value: object
    evidence: Evidence


@dataclass(frozen=True, slots=True)
class RawClaim:
    expr: object  # plain data in the policy format's expression shape
    quote: str


@dataclass(frozen=True, slots=True)
class Rejected:
    """Something a guard dropped: the variable name or the claim's quote, and why."""
    item: str
    reason: str
```

Create `src/policyproof/guards/values.py`:

```python
"""Reading a reader's plain value as a literal of a variable's sort, and finding a quote in a text."""
from fractions import Fraction

from returns.result import Failure, Result, Success

from policyproof.core.check import normalize
from policyproof.core.syntax import (
    BoolLit,
    BoolSort,
    EnumLit,
    EnumSort,
    IntLit,
    IntSort,
    Lit,
    Policy,
    RealLit,
    RealSort,
)
from policyproof.core.typecheck import sort_name


def literal_for(p: Policy, var: str, value: object) -> Result[Lit, str]:
    """`value` as a literal of `var`'s sort. Booleans may be `true`/`false` strings (as Jev's options are); enum
    values may be written `VALUE` or `Sort.VALUE`, in any case if that is unambiguous; reals are ints or
    `{"real": "2.5"}` (never floats, which are inexact)."""
    variable = next((v for v in p.variables if v.name == var), None)
    if variable is None:
        return Failure(f"unknown variable {var!r}")
    bad = Failure(f"{value!r} is not a {sort_name(variable.sort)} value for {var}")
    match variable.sort, value:
        case BoolSort(), bool():
            return Success(BoolLit(value))
        case BoolSort(), str() if value.lower() in ("true", "false"):
            return Success(BoolLit(value.lower() == "true"))
        case IntSort(), int() if not isinstance(value, bool):
            return Success(IntLit(value))
        case RealSort(), int() if not isinstance(value, bool):
            return Success(RealLit(Fraction(value)))
        case RealSort(), {"real": str() | int() as text} if len(value) == 1:
            try:
                return Success(RealLit(Fraction(text)))
            except ValueError:
                return bad
        case EnumSort(name, values), str():
            short = value.split(".", 1)[1] if value.lower().startswith(f"{name.lower()}.") else value
            same = [v for v in values if v == short] or [v for v in values if v.lower() == short.lower()]
            return Success(EnumLit(name, same[0])) if len(same) == 1 else bad
        case _:
            return bad


def in_text(quote: str, text: str) -> bool:
    """`quote` occurs in `text` as whole words, ignoring case and punctuation (the core's `normalize`)."""
    q = normalize(quote)
    return bool(q) and f" {q} " in f" {normalize(text)} "
```

```python
"""Checking a reader's answer to the question the customer was asked.

The answer becomes a fact only if its quote is in the message, its value has the variable's sort, and, for a yes/no
question, it doesn't contradict a plain "yes" or "no" the message opens with ("Yes, please cancel it" read as false
is unclear, not false). Everything else is `Unclear`, so the question is asked again.
"""
import re
from dataclasses import dataclass
from typing import assert_never

from returns.result import Failure, Success

from policyproof.core._result import unreachable
from policyproof.core.facts import Answered, Fact
from policyproof.core.syntax import Ask, BoolLit, BoolSort, Policy
from policyproof.guards.raw import NotAnswered, RawAnswer, Said, Unclear
from policyproof.guards.values import in_text, literal_for

YES = r"(yes|yeah|yep|yup|sure|correct|that's right|that is right)"
NO = r"(no|nope|nah|not really)"


@dataclass(frozen=True, slots=True)
class Answer:
    fact: Fact


type Reading = Answer | Unclear | NotAnswered


def opening_word(message: str) -> bool | None:
    """True or False if the message opens with a plain yes or no word, else None."""
    text = message.strip().lower()
    if re.match(rf"{YES}\b", text):
        return True
    if re.match(rf"{NO}\b", text):
        return False
    return None


def check(p: Policy, var: str, message: str, raw: RawAnswer) -> Reading:
    variable = next((v for v in p.variables if v.name == var), None)
    if variable is None or not isinstance(variable.role, Ask):
        return Unclear("not an askable variable")
    match raw:
        case Said(value, quote):
            if not in_text(quote, message):
                return Unclear("quote not in message")
            match literal_for(p, var, value):
                case Failure(reason):
                    return Unclear(reason)
                case Success(lit):
                    lead = opening_word(message)
                    if isinstance(variable.sort, BoolSort) and lead is not None and BoolLit(lead) != lit:
                        return Unclear("opening contradicts answer")
                    return Answer(Fact(var, lit, Answered(variable.role.question, quote)))
                case _:
                    unreachable()
        case Unclear() | NotAnswered():
            return raw
        case _:
            assert_never(raw)
```

Create `src/policyproof/guards/facts.py`:

```python
"""Checking facts a reader found in a message (things the customer said without being asked).

A fact is kept only if its variable exists and isn't derived, its value has the variable's sort, and its evidence
holds: a quote must be in the message, a confidence must reach the bar. Kept facts are merged with the core's
`merge`, so two kept facts that conflict both stay, and `decide` reports the contradiction.
"""
from collections.abc import Sequence
from typing import assert_never

from returns.result import Failure, Result, Success

from policyproof.core._result import unreachable
from policyproof.core.facts import Fact, Facts, Quoted, Scored, Volunteered, facts
from policyproof.core.syntax import Derived, Policy
from policyproof.guards.raw import RawFact, Rejected
from policyproof.guards.values import in_text, literal_for


def _fact(p: Policy, message: str, raw: RawFact, min_confidence: float) -> Result[Fact, str]:
    variable = next((v for v in p.variables if v.name == raw.var), None)
    if variable is not None and isinstance(variable.role, Derived):
        return Failure(f"{raw.var} is derived by the rules; it can't be given as a fact")
    match raw.evidence:
        case Quoted(text) if not in_text(text, message):
            return Failure("quote not in message")
        case Scored(confidence) if confidence < min_confidence:
            return Failure(f"confidence {confidence:g} is below {min_confidence:g}")
        case Quoted() | Scored():
            return literal_for(p, raw.var, raw.value).map(lambda lit: Fact(raw.var, lit, Volunteered(raw.evidence)))
        case _:
            assert_never(raw.evidence)


def check(p: Policy, message: str, raws: Sequence[RawFact], *, min_confidence: float = 0.5
          ) -> tuple[Facts, tuple[Rejected, ...]]:
    kept: list[Fact] = []
    rejected: list[Rejected] = []
    for raw in raws:
        match _fact(p, message, raw, min_confidence):
            case Success(f):
                kept.append(f)
            case Failure(reason):
                rejected.append(Rejected(raw.var, reason))
            case _:
                unreachable()
    return facts(*kept), tuple(rejected)
```

Create `src/policyproof/guards/claims.py`:

```python
"""Checking claims a reader found in a reply, before the core judges them.

A claim is kept only if its expression decodes against the policy, is a true/false statement, mentions at least one
policy variable (a bare `true` claims nothing), and its quote is in the reply.
"""
from collections.abc import Sequence

from returns.result import Failure, Result, Success

from policyproof.core._result import unreachable
from policyproof.core.check import Claim
from policyproof.core.codec import decode_expr, from_data
from policyproof.core.semantics import free_vars
from policyproof.core.syntax import BOOL, Expr, Policy
from policyproof.core.typecheck import Signature, signature, sort_of
from policyproof.guards.raw import RawClaim, Rejected
from policyproof.guards.values import in_text


def _expr(sig: Signature, data: object) -> Result[Expr, str]:
    match from_data(data).bind(lambda t: decode_expr(sig, t, "expr")):
        case Success(e):
            if sort_of(sig, e) != Success(BOOL):
                return Failure("not a true/false statement")
            if not free_vars(e):
                return Failure("mentions no policy variable")
            return Success(e)
        case Failure(err):
            return Failure(f"{err.path}: {err.message}")
        case _:
            unreachable()


def check(p: Policy, reply: str, raws: Sequence[RawClaim]) -> tuple[tuple[Claim, ...], tuple[Rejected, ...]]:
    sig = signature(p)
    kept: list[Claim] = []
    rejected: list[Rejected] = []
    for raw in raws:
        result = _expr(sig, raw.expr) if in_text(raw.quote, reply) else Failure("quote not in reply")
        match result:
            case Success(e):
                kept.append(Claim(e, raw.quote))
            case Failure(reason):
                rejected.append(Rejected(raw.quote, reason))
            case _:
                unreachable()
    return tuple(kept), tuple(rejected)
```

```python
"""Deciding without trusting weak facts blindly (the lab's V5 re-check).

A weak fact is one a reader only scored (it couldn't quote it) below `firm_confidence`. The decision is made twice,
with and without the weak facts. If both reach the same conclusion, the weak facts didn't matter. If not, one of them
was decisive, so instead of deciding on it the customer is asked to confirm it.
"""
from typing import assert_never

from policyproof.core.decide import (
    Contradiction,
    Decided,
    Decision,
    Escalate,
    InvalidFacts,
    NeedInfo,
    decide,
    firm_facts,
    what_if,
)
from policyproof.core.facts import Fact, Facts, Scored, Volunteered, all_facts, facts
from policyproof.core.solver import Compiled
from policyproof.core.syntax import Ask


def _weak(f: Fact, firm_confidence: float) -> bool:
    match f.provenance:
        case Volunteered(Scored(confidence)):
            return confidence < firm_confidence
        case _:
            return False


def _conclusion(d: Decision) -> tuple[str, str]:
    """What a decision concludes, ignoring which facts it cites."""
    match d:
        case Decided(outcome, _, _):
            return "decided", outcome
        case NeedInfo(var, _, _, _):
            return "ask", var
        case Contradiction():
            return "contradiction", ""
        case Escalate():
            return "escalate", ""
        case InvalidFacts():
            return "invalid", ""
        case _:
            assert_never(d)


def _used(d: Decision) -> frozenset[str]:
    match d:
        case Decided(_, _, used) | Contradiction(_, used):
            return frozenset(f.var for f in used)
        case NeedInfo() | Escalate() | InvalidFacts():
            return frozenset()
        case _:
            assert_never(d)


def decide_robustly(c: Compiled, fs: Facts, *, unclear: frozenset[str] = frozenset(),
                    firm_confidence: float = 0.8) -> Decision:
    every = all_facts(fs)
    weak = tuple(f for f in every if _weak(f, firm_confidence))
    with_weak = decide(c, fs, unclear=unclear)
    if not weak:
        return with_weak
    strong = facts(*(f for f in every if f not in weak))
    without = decide(c, strong, unclear=unclear)
    if _conclusion(with_weak) == _conclusion(without):
        return with_weak
    askable = {v.name: v.role for v in c.policy.variables if isinstance(v.role, Ask)}
    weak_vars = {f.var for f in weak if f.var in askable}
    if not weak_vars:
        return without  # nobody can be asked about these, so decide as if they weren't said
    used = _used(with_weak)
    order = [v.name for v in c.policy.variables if v.name in weak_vars]
    var = next((n for n in order if n in used), order[0])
    role = askable[var]
    assert isinstance(role, Ask)
    return NeedInfo(var, role.question, "confirm", what_if(c, firm_facts(c, strong), var))
```

```python
"""Why a reader produced nothing. A guard rejecting what a reader produced is not an error (see `guards`)."""
from dataclasses import dataclass
from typing import assert_never


@dataclass(frozen=True, slots=True)
class Unavailable:
    """The provider couldn't be reached or refused the request: network, throttling, authentication, 5xx."""
    message: str


@dataclass(frozen=True, slots=True)
class Malformed:
    """The model's output never passed validation, even after the allowed retries."""
    message: str


@dataclass(frozen=True, slots=True)
class Refused:
    """The model declined, a content filter fired, or Jev handed the step off as too uncertain."""
    message: str


type LLMError = Unavailable | Malformed | Refused


def describe(e: LLMError) -> str:
    match e:
        case Unavailable(m):
            return f"provider unavailable: {m}"
        case Malformed(m):
            return f"unusable output: {m}"
        case Refused(m):
            return f"refused: {m}"
        case _:
            assert_never(e)
```

Create `src/policyproof/effects/consensus.py`:

```python
"""Two readers as one, combined so that a disagreement errs on the safe side.

- `AgreeingFacts` keeps only facts both readers found: fewer facts means more questions, never a wrong decision.
- `AgreeingAnswers` accepts an answer only if both read the same value; otherwise the question is asked again.
- `UnionClaims` checks every claim either reader found: more claims can only fail more drafts.

Values are compared as policy literals, so Jev's `"true"` agrees with an LLM's `True`. If one reader fails, the other's
result is used; if both fail, the first error is returned. Ports return only a `Result`, so a one-sided failure and a
disagreement are reported on the `policyproof.consensus` logger at WARNING.
"""
import asyncio
import json
import logging
from collections.abc import Awaitable, Sequence
from dataclasses import dataclass

from returns.result import Failure, Result, Success

from policyproof.core._result import unreachable
from policyproof.core.facts import Evidence, Quoted, Scored
from policyproof.core.syntax import CheckedPolicy, Lit, Policy
from policyproof.effects.errors import LLMError, describe
from policyproof.effects.ports import (
    AnswerReader,
    ClaimReader,
    FactReader,
    NotAnswered,
    RawAnswer,
    RawClaim,
    RawFact,
    Said,
    Unclear,
)
from policyproof.guards.values import in_text, literal_for

log = logging.getLogger("policyproof.consensus")


async def _both[T](a: Awaitable[Result[T, LLMError]], b: Awaitable[Result[T, LLMError]]
                   ) -> tuple[Result[T, LLMError], Result[T, LLMError]]:
    ra, rb = await asyncio.gather(a, b)
    match ra, rb:
        case (Failure(e), Success(_)) | (Success(_), Failure(e)):
            log.warning("one reader failed, using the other: %s", describe(e))
        case _:
            pass
    return ra, rb


def _either[T](ra: Result[T, LLMError], rb: Result[T, LLMError]) -> Result[T, LLMError]:
    """The successful side when only one succeeded, else `ra` (its error when both failed)."""
    return rb if isinstance(ra, Failure) and isinstance(rb, Success) else ra


def _key(p: Policy, f: RawFact) -> tuple[str, Lit] | None:
    lit = literal_for(p, f.var, f.value).value_or(None)
    return None if lit is None else (f.var, lit)


def _evidence(a: Evidence, b: Evidence) -> Evidence:
    match a, b:
        case Quoted(), _:
            return a
        case _, Quoted():
            return b
        case Scored(x), Scored(y):
            return Scored(min(x, y))
        case _:
            unreachable()


def agree_facts(p: Policy, a: Sequence[RawFact], b: Sequence[RawFact]) -> tuple[RawFact, ...]:
    first_b: dict[tuple[str, Lit], RawFact] = {}
    for f in b:
        k = _key(p, f)
        if k is not None:
            first_b.setdefault(k, f)
    kept: dict[tuple[str, Lit], RawFact] = {}
    for f in a:
        k = _key(p, f)
        if k is not None and k in first_b and k not in kept:
            kept[k] = RawFact(f.var, f.value, _evidence(f.evidence, first_b[k].evidence))
    agreed = {var for var, _ in kept}
    for var in sorted(({f.var for f in a} & {f.var for f in b}) - agreed):
        log.warning("readers disagree on %s; dropping it", var)
    return tuple(kept.values())


def agree_answers(p: Policy, var: str, message: str, a: RawAnswer, b: RawAnswer) -> RawAnswer:
    match a, b:
        case Said(x, qa), Said(y, qb):
            lx, ly = literal_for(p, var, x).value_or(None), literal_for(p, var, y).value_or(None)
            if x != y and (lx is None or lx != ly):
                return Unclear("readers disagree")
            return Said(x, qa if in_text(qa, message) or not in_text(qb, message) else qb)
        case NotAnswered(), NotAnswered():
            return a
        case Unclear(), Unclear():
            return a
        case _:
            return Unclear("readers disagree")


def union_claims(a: Sequence[RawClaim], b: Sequence[RawClaim]) -> tuple[RawClaim, ...]:
    seen: dict[tuple[str, str], RawClaim] = {}
    for c in (*a, *b):
        seen.setdefault((json.dumps(c.expr, sort_keys=True, default=str), c.quote), c)
    return tuple(seen.values())


@dataclass(frozen=True, slots=True)
class AgreeingFacts:
    a: FactReader
    b: FactReader

    async def read_facts(self, p: CheckedPolicy, message: str) -> Result[tuple[RawFact, ...], LLMError]:
        ra, rb = await _both(self.a.read_facts(p, message), self.b.read_facts(p, message))
        match ra, rb:
            case Success(xs), Success(ys):
                return Success(agree_facts(p, xs, ys))
            case _:
                return _either(ra, rb)


@dataclass(frozen=True, slots=True)
class AgreeingAnswers:
    a: AnswerReader
    b: AnswerReader

    async def read_answer(self, p: CheckedPolicy, var: str, message: str) -> Result[RawAnswer, LLMError]:
        ra, rb = await _both(self.a.read_answer(p, var, message), self.b.read_answer(p, var, message))
        match ra, rb:
            case Success(x), Success(y):
                return Success(agree_answers(p, var, message, x, y))
            case _:
                return _either(ra, rb)


@dataclass(frozen=True, slots=True)
class UnionClaims:
    a: ClaimReader
    b: ClaimReader

    async def read_claims(self, p: CheckedPolicy, reply: str) -> Result[tuple[RawClaim, ...], LLMError]:
        ra, rb = await _both(self.a.read_claims(p, reply), self.b.read_claims(p, reply))
        match ra, rb:
            case Success(xs), Success(ys):
                return Success(union_claims(xs, ys))
            case _:
                return _either(ra, rb)
```

```python
"""The two turn pipelines.

`read_turn` reads a customer message into facts and a decision. `guard_reply` checks a drafted reply before it is
sent, rewrites it once if it fails, and otherwise sends a deterministic fallback, so unchecked text never reaches the
customer. Both fail closed: an error means asking again or the fallback, never a decision or a claim on less evidence.
"""
import asyncio
import dataclasses
from collections.abc import Callable
from dataclasses import dataclass
from typing import assert_never

from returns.result import Failure, Result, Success

from policyproof.core._result import unreachable
from policyproof.core.check import DEFAULT_RULES, CheckResult, Problem, ReplyRule, check_reply
from policyproof.core.decide import Contradiction, Decided, Decision, Escalate, InvalidFacts, NeedInfo
from policyproof.core.facts import Facts, merge
from policyproof.core.solver import Compiled
from policyproof.effects.errors import LLMError, describe
from policyproof.effects.ports import AnswerReader, ClaimReader, FactReader, RawAnswer, Rejected, Rewriter
from policyproof.guards import answer, claims, facts
from policyproof.guards.answer import Answer, Reading
from policyproof.guards.raw import NotAnswered, Unclear
from policyproof.guards.robust import decide_robustly


@dataclass(frozen=True, slots=True)
class Conversation:
    facts: Facts  # including the system facts the caller loaded
    pending: NeedInfo | None  # the question asked last turn
    unclear: frozenset[str]  # variables whose last answer couldn't be read


@dataclass(frozen=True, slots=True)
class Readers:
    answers: AnswerReader
    facts: FactReader


@dataclass(frozen=True, slots=True)
class Turn:
    state: Conversation  # the state for the next turn: `pending` is the decision if it asks a question
    decision: Decision
    answer: Reading | None  # None when no question was pending
    rejected: tuple[Rejected, ...]
    degraded: tuple[LLMError, ...]  # errors the turn went on without


async def _no_answer() -> Result[RawAnswer | None, LLMError]:
    return Success(None)


async def read_turn(c: Compiled, state: Conversation, message: str, r: Readers, *,
                    min_confidence: float = 0.5, firm_confidence: float = 0.8) -> Result[Turn, LLMError]:
    p = c.policy
    asking = r.answers.read_answer(p, state.pending.var, message) if state.pending else _no_answer()
    raw_answer, raw_facts = await asyncio.gather(asking, r.facts.read_facts(p, message))
    match raw_answer:
        case Failure(e):
            return Failure(e)
        case Success(raw):
            pass
        case _:
            unreachable()
    known, unclear = state.facts, state.unclear
    reading: Reading | None = None
    if state.pending is not None and raw is not None:
        var = state.pending.var
        reading = answer.check(p, var, message, raw)
        match reading:
            case Answer(fact):
                known, unclear = merge(known, {var: frozenset({fact})}), unclear - {var}
            case Unclear():
                unclear = unclear | {var}
            case NotAnswered():
                pass
            case _:
                assert_never(reading)
    rejected: tuple[Rejected, ...] = ()
    degraded: tuple[LLMError, ...] = ()
    match raw_facts:
        case Success(found):
            said, rejected = facts.check(p, message, found, min_confidence=min_confidence)
            known = merge(known, said)
        case Failure(e):
            degraded = (e,)
        case _:
            unreachable()
    decision = decide_robustly(c, known, unclear=unclear, firm_confidence=firm_confidence)
    pending = decision if isinstance(decision, NeedInfo) else None
    return Success(Turn(Conversation(known, pending, unclear), decision, reading, rejected, degraded))


# ---- replies


def template(d: Decision) -> str:
    """The fallback reply: plain, deterministic, and only what the decision itself says."""
    match d:
        case Decided(outcome, _, _):
            return f"Under the policy, the outcome is {outcome.replace('_', ' ')}."
        case NeedInfo(_, question, _, _):
            return question
        case Contradiction():
            return "Some of the information conflicts; a person will review this."
        case Escalate() | InvalidFacts():
            return "A person will review this."
        case _:
            assert_never(d)


@dataclass(frozen=True, slots=True)
class Guarded:
    text: str
    attempts: int  # drafts checked: 1 or 2
    result: CheckResult | None  # the last check that ran; None if none could
    fell_back: bool
    reason: str | None  # why it fell back


async def _check(c: Compiled, fs: Facts, d: Decision, reply: str, reader: ClaimReader,
                 rules: tuple[ReplyRule, ...]) -> Result[CheckResult, LLMError]:
    """The core's check, plus one problem per claim the guard rejected: a claim that can't be checked fails it."""
    match await reader.read_claims(c.policy, reply):
        case Success(raws):
            kept, rejected = claims.check(c.policy, reply, raws)
            result = check_reply(c, d, fs, reply, kept, rules)
            unreadable = tuple(Problem("claims_readable", f'"{r.item}" can\'t be checked: {r.reason}')
                               for r in rejected)
            if not unreadable:
                return Success(result)
            return Success(dataclasses.replace(result, passed=False, problems=result.problems + unreadable))
        case Failure(e):
            return Failure(e)
        case _:
            unreachable()


async def guard_reply(c: Compiled, fs: Facts, decision: Decision, draft: str, reader: ClaimReader,
                      rewriter: Rewriter, *, rules: tuple[ReplyRule, ...] = DEFAULT_RULES, instructions: str = "",
                      fallback: Callable[[Decision], str] = template) -> Guarded:
    def fall_back(attempts: int, result: CheckResult | None, reason: str) -> Guarded:
        return Guarded(fallback(decision), attempts, result, True, reason)

    match await _check(c, fs, decision, draft, reader, rules):
        case Failure(e):
            return fall_back(1, None, describe(e))
        case Success(first):
            pass
        case _:
            unreachable()
    if first.passed:
        return Guarded(draft, 1, first, False, None)
    match await rewriter.rewrite(draft, first.problems, instructions):
        case Failure(e):
            return fall_back(1, first, describe(e))
        case Success(rewrite):
            pass
        case _:
            unreachable()
    match await _check(c, fs, decision, rewrite, reader, rules):
        case Failure(e):
            return fall_back(2, first, describe(e))
        case Success(second) if second.passed:
            return Guarded(rewrite, 2, second, False, None)
        case Success(second):
            return fall_back(2, second, "the reply failed the check twice")
        case _:
            unreachable()
```

```python
"""The policy format's expression grammar as recursive pydantic models: the schema an LLM fills to report claims.

pydantic-ai can't take our published JSON Schema as an output type (its `StructuredDict` refuses recursive `$defs`),
so the grammar is mirrored here. Law E1 keeps the two in step; `codec.decode_expr` is still what reads the result.
"""
from __future__ import annotations

from pydantic import BaseModel, ConfigDict, Field


class _Op(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True, validate_by_name=True, serialize_by_alias=True)


class Real(_Op):
    """An exact number, e.g. {"real": "2.5"} or {"real": "1/3"}."""
    real: str | int


class Not(_Op):
    not_: Expr = Field(alias="not")


class And(_Op):
    and_: list[Expr] = Field(alias="and", min_length=2)


class Or(_Op):
    or_: list[Expr] = Field(alias="or", min_length=2)


class Implies(_Op):
    implies: list[Expr] = Field(min_length=2, max_length=2)


class Iff(_Op):
    iff: list[Expr] = Field(min_length=2, max_length=2)


class Eq(_Op):
    eq: list[Expr] = Field(min_length=2, max_length=2)


class Ne(_Op):
    ne: list[Expr] = Field(min_length=2, max_length=2)


class Lt(_Op):
    lt: list[Expr] = Field(min_length=2, max_length=2)


class Le(_Op):
    le: list[Expr] = Field(min_length=2, max_length=2)


class Gt(_Op):
    gt: list[Expr] = Field(min_length=2, max_length=2)


class Ge(_Op):
    ge: list[Expr] = Field(min_length=2, max_length=2)


class Add(_Op):
    add: list[Expr] = Field(min_length=2)


class Sub(_Op):
    sub: list[Expr] = Field(min_length=2, max_length=2)


class Mul(_Op):
    mul: list[Expr] = Field(min_length=2)


class In(_Op):
    """Membership: {"in": [expr, [value, ...]]}."""
    in_: tuple[Expr, list[bool | int | str | Real]] = Field(alias="in")


type Expr = (bool | int | str | Real | Not | And | Or | Implies | Iff | Eq | Ne | Lt | Le | Gt | Ge | Add | Sub | Mul
             | In)


class Claim(_Op):
    """One checkable statement the reply makes."""
    expr: Expr = Field(description="The statement, as an expression over the policy's variables.")
    quote: str = Field(description="The exact words of the reply that make this statement.")


class Claims(_Op):
    """Every checkable statement the reply makes about the policy's variables."""
    claims: list[Claim]
```

```python
"""The instructions each LLM reader sends, built from the policy. Pure functions, so they are tested as snapshots."""
from collections.abc import Iterable
from typing import assert_never

from policyproof.core.check import Problem
from policyproof.core.syntax import Ask, BoolSort, Derived, EnumSort, IntSort, Policy, RealSort, Sort, Variable


def values_of(s: Sort) -> str:
    match s:
        case BoolSort():
            return "true or false"
        case IntSort():
            return "a whole number"
        case RealSort():
            return 'a number, written {"real": "2.5"}'
        case EnumSort(_, values):
            return "one of " + ", ".join(values)
        case _:
            assert_never(s)


def describe(vs: Iterable[Variable]) -> str:
    return "\n".join(f"- {v.name} ({values_of(v.sort)}): {v.description}" for v in vs)


def examples(p: Policy) -> str:
    """Example expressions using the policy's own names: one per kind of variable the policy has."""
    found: list[str] = []
    for v in p.variables:
        match v.sort:
            case BoolSort() if not any(e.startswith('"') for e in found):
                found += [f'"{v.name}"', f'{{"not": "{v.name}"}}']
            case EnumSort(_, values) if not any('"eq"' in e for e in found):
                found.append(f'{{"eq": ["{v.name}", "{values[0]}"]}}')
            case IntSort() if not any('"ge"' in e for e in found):
                found.append(f'{{"ge": ["{v.name}", 2]}}')
            case RealSort() if not any('"ge"' in e for e in found):
                found.append(f'{{"ge": ["{v.name}", {{"real": "2.5"}}]}}')
            case _:
                pass
    return ", ".join(found)


def answer_prompt(p: Policy, var: str) -> str:
    v = next(x for x in p.variables if x.name == var)
    assert isinstance(v.role, Ask)
    return f"""You read a customer's reply to one question and decide whether it answers it.

QUESTION ASKED: {v.role.question}

- status "answered" when the reply gives one clear answer: set value, and quote the reply's exact words that give it.

- status "not_answered" when the reply doesn't answer the question (for example, it asks something else).
Never guess. Quote word for word."""


def facts_prompt(p: Policy) -> str:
    asked = [v for v in p.variables if not isinstance(v.role, Derived)]
    return f"""You find facts a customer states in a message, for these variables only:
{describe(asked)}

Report a fact only when the message states it; don't infer one from tone or context. For each fact, quote the
message's exact words that state it. Report nothing for a variable the message doesn't mention."""

    return f"""You list every checkable statement a support reply makes about these policy variables:

apologies and questions."""

Problems:
{listed}{extra}"""
```

```python
"""All four ports on any chat model pydantic-ai supports.

Each call runs one pydantic-ai `Agent` with a structured output type. The matching guard runs in the agent's output
validator, so an output the guard rejects is sent back once with the guard's reasons (`retries`). When the retries run
out, facts and claims are `Malformed` (the pipelines then go on without facts or fall back), while an answer is
`Unclear`, so the question is asked again rather than the turn failing.
"""
from dataclasses import dataclass, field
from typing import Literal

from pydantic import BaseModel, ConfigDict, Field
from pydantic_ai import Agent, ModelRetry
from pydantic_ai.exceptions import ContentFilterError, ModelAPIError, UnexpectedModelBehavior
from pydantic_ai.models import Model
from pydantic_ai.settings import ModelSettings
from returns.result import Failure, Result, Success

from policyproof.core._result import unreachable
from policyproof.core.check import Problem
from policyproof.core.facts import Quoted
from policyproof.core.syntax import CheckedPolicy
from policyproof.effects.errors import LLMError, Malformed, Refused, Unavailable
from policyproof.effects.llm.exprmodel import Claims, Real
from policyproof.effects.llm.prompts import answer_prompt, claims_prompt, facts_prompt, rewrite_prompt
from policyproof.effects.ports import NotAnswered, RawAnswer, RawClaim, RawFact, Rejected, Said, Unclear
from policyproof.guards import answer, claims, facts

type Value = bool | int | str | Real


class _Out(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True)


class AnswerOut(_Out):
    """How the customer's reply answers the question."""
    status: Literal["answered", "unclear", "not_answered"]
    value: Value | None = Field(None, description="The answer, when status is answered.")
    quote: str | None = Field(None, description="The reply's exact words that give the answer.")
    reason: str | None = Field(None, description="Why the reply can't be read, when status is unclear.")


class FactOut(_Out):
    var: str = Field(description="The variable's name, exactly as listed.")
    value: Value
    quote: str = Field(description="The message's exact words that state the fact.")


class FactsOut(_Out):
    """Every fact the message states about the listed variables."""
    facts: list[FactOut]


def _plain(v: Value | None) -> object:
    return v.model_dump() if isinstance(v, Real) else v


def _raw_answer(out: AnswerOut) -> RawAnswer:
    match out.status:
        case "answered" if out.quote is not None and out.value is not None:
            return Said(_plain(out.value), out.quote)
        case "answered":
            return Unclear("answered without a value and a quote")
        case "unclear":
            return Unclear(out.reason or "unclear")
        case "not_answered":
            return NotAnswered()


def _raw_facts(out: FactsOut) -> tuple[RawFact, ...]:
    return tuple(RawFact(f.var, _plain(f.value), Quoted(f.quote)) for f in out.facts)


def _raw_claims(out: Claims) -> tuple[RawClaim, ...]:
    return tuple(RawClaim(c.model_dump()["expr"], c.quote) for c in out.claims)


def _reasons(rejected: tuple[Rejected, ...]) -> str:
    return "; ".join(f"{r.item}: {r.reason}" for r in rejected)


async def _run[T](agent: Agent[None, T], prompt: str) -> Result[T, LLMError]:
    try:
        return Success((await agent.run(prompt)).output)
    except ContentFilterError as e:
        return Failure(Refused(str(e)))
    except UnexpectedModelBehavior as e:
        return Failure(Malformed(str(e)))
    except ModelAPIError as e:
        return Failure(Unavailable(str(e)))


@dataclass(frozen=True, slots=True)
class LLMReaders:
    """An `AnswerReader`, `FactReader`, `ClaimReader` and `Rewriter` on one pydantic-ai model."""
    model: Model
    retries: int = 1
    rewrite_settings: ModelSettings = field(default_factory=lambda: ModelSettings(temperature=0.3))

    def _agent[T](self, output: type[T], instructions: str) -> Agent[None, T]:
        return Agent(self.model, output_type=output, instructions=instructions, retries={"output": self.retries})

    async def read_answer(self, p: CheckedPolicy, var: str, message: str) -> Result[RawAnswer, LLMError]:
        agent = self._agent(AnswerOut, answer_prompt(p, var))

        @agent.output_validator
        def _guard(out: AnswerOut) -> AnswerOut:
            raw = _raw_answer(out)
            if isinstance(raw, Said) and isinstance(reading := answer.check(p, var, message, raw), Unclear):
                raise ModelRetry(f"answer rejected: {reading.reason}")
            return out

        match await _run(agent, message):
            case Success(out):
                return Success(_raw_answer(out))
            case Failure(Malformed(reason)):
                return Success(Unclear(f"the answer couldn't be read: {reason}"))
            case Failure(e):
                return Failure(e)
            case _:
                unreachable()

    async def read_facts(self, p: CheckedPolicy, message: str) -> Result[tuple[RawFact, ...], LLMError]:
        agent = self._agent(FactsOut, facts_prompt(p))

        @agent.output_validator
        def _guard(out: FactsOut) -> FactsOut:
            _, rejected = facts.check(p, message, _raw_facts(out))
            if rejected:
                raise ModelRetry(f"facts rejected: {_reasons(rejected)}")
            return out

        return (await _run(agent, message)).map(_raw_facts)

    async def read_claims(self, p: CheckedPolicy, reply: str) -> Result[tuple[RawClaim, ...], LLMError]:
        agent = self._agent(Claims, claims_prompt(p))

        @agent.output_validator
        def _guard(out: Claims) -> Claims:
            _, rejected = claims.check(p, reply, _raw_claims(out))
            if rejected:
                raise ModelRetry(f"claims rejected: {_reasons(rejected)}")
            return out

        return (await _run(agent, reply)).map(_raw_claims)

    async def rewrite(self, draft: str, problems: tuple[Problem, ...], instructions: str) -> Result[str, LLMError]:
        agent = Agent(self.model, output_type=str, instructions=rewrite_prompt(problems, instructions),
                      model_settings=self.rewrite_settings)
        return await _run(agent, draft)
```

```python
        self.picks, self.questions = picks, {}

    async def decide(self, request: DecisionRequest, model_settings: DecisionModelSettings) -> DecisionResponse:
```

```python
"""Facts and answers from Jev.

Jev answers typed questions with probabilities instead of writing text. pydantic-ai's `TypeSafeModel` turns an
output type into Jev questions, so each reader builds one from the policy: a pick-one per variable, over the
variable's values plus "not stated" (facts) or "unclear" and "not answered" (answers). Jev can't point to the words it
read, so facts carry `Scored` evidence (its confidence) and an answer quotes the whole message. Int and Real
variables can't be asked as a pick-one: facts skip them and an answer to one is `Refused`, so pair Jev with an LLM
(`consensus.AgreeingFacts`, `AgreeingAnswers`) for those.
"""
from dataclasses import dataclass
from typing import Annotated, Any, assert_never

from pydantic import BaseModel, Field, create_model
from pydantic_ai import Agent, Choices
from pydantic_ai.exceptions import ModelAPIError, UnexpectedModelBehavior
from pydantic_ai.messages import ModelResponse
from pydantic_ai.models import Model
from pydantic_ai.models.decision import DecisionHandOff
from pydantic_ai.run import AgentRunResult
from returns.result import Failure, Result, Success

from policyproof.core._result import unreachable
from policyproof.core.facts import Scored
from policyproof.core.syntax import Ask, BoolSort, CheckedPolicy, Derived, EnumSort, IntSort, RealSort, Sort, Variable
from policyproof.effects.errors import LLMError, Malformed, Refused, Unavailable
from policyproof.effects.ports import NotAnswered, RawAnswer, RawFact, Said, Unclear

NOT_STATED, UNCLEAR, NOT_ANSWERED = "not_stated", "unclear", "not_answered"


def options(v: Variable) -> dict[str, str] | None:
    """The variable's values as described pick-one options, or None if it can't be asked as one."""
    s: Sort = v.sort
    match s:
        case BoolSort():
            return {"true": f"Yes: {v.description}", "false": f"No, the opposite: {v.description}"}
        case EnumSort(_, values):
            return {x: f"{v.description}: {x}" for x in values}
        case IntSort() | RealSort():
            return None
        case _:
            assert_never(s)


def question(v: Variable) -> str:
    return v.role.question if isinstance(v.role, Ask) else v.description


def facts_type(p: CheckedPolicy) -> type[BaseModel] | None:
    """One pick-one field per variable Jev can be asked about, or None if there is none. Fields are named `f0`, `f1`,
    ... and carry the variable's name as their alias, so a variable named like a pydantic attribute still works."""
    fields: dict[str, Any] = {}
    for v in p.variables:
        found = options(v)
        if found is not None and not isinstance(v.role, Derived):
            choices = Choices({**found, NOT_STATED: "The message doesn't say."})
            fields[f"f{len(fields)}"] = (Annotated[str, choices, Field(alias=v.name, description=question(v))], ...)
    if not fields:
        return None
    return create_model("Facts", __doc__="What the customer's message states about each variable.", **fields)


def answer_type(v: Variable) -> type[str]:
    found = options(v) or {}
    return Choices({**found, UNCLEAR: "The reply tries to answer but can't be read as one of these.",
                    NOT_ANSWERED: "The reply doesn't answer the question."}, name=v.name, description=question(v))


def confidences(run: AgentRunResult[Any]) -> dict[str, float]:
    found: dict[str, float] = {}
    for m in run.all_messages():
        if isinstance(m, ModelResponse) and m.provider_details:
            found.update(m.provider_details.get("confidence", {}))
    return found


async def _run[T](agent: Agent[None, T], prompt: str) -> Result[AgentRunResult[T], LLMError]:
    try:
        return Success(await agent.run(prompt))
    except DecisionHandOff as e:
        return Failure(Refused(str(e)))
    except UnexpectedModelBehavior as e:
        return Failure(Malformed(str(e)))
    except ModelAPIError as e:
        return Failure(Unavailable(str(e)))


@dataclass(frozen=True, slots=True)
class JevReaders:
    """A `FactReader` and an `AnswerReader` on Jev. Pass a `TypeSafeModel` (pin a version, e.g. `jev-1.13.0`)."""
    model: Model
    min_confidence: float = 0.5

    async def read_facts(self, p: CheckedPolicy, message: str) -> Result[tuple[RawFact, ...], LLMError]:
        output = facts_type(p)
        if output is None:
            return Success(())
        match await _run(Agent(self.model, output_type=output), message):
            case Success(run):
                conf = confidences(run)
                picked = run.output.model_dump(by_alias=True)
                return Success(tuple(RawFact(var, value, Scored(conf.get(var, 0.0)))
                                     for var, value in picked.items() if value != NOT_STATED))
            case Failure(e):
                return Failure(e)
            case _:
                unreachable()

    async def read_answer(self, p: CheckedPolicy, var: str, message: str) -> Result[RawAnswer, LLMError]:
        v = next(x for x in p.variables if x.name == var)
        if options(v) is None:
            return Failure(Refused(f"Jev can't read a number for {var}; use an LLM reader for it"))
        agent = Agent(self.model, output_type=answer_type(v))
        match await _run(agent, message):
            case Success(run):
                confidence = next(iter(confidences(run).values()), 0.0)
                if run.output == NOT_ANSWERED:
                    return Success(NotAnswered())
                if run.output == UNCLEAR:
                    return Success(Unclear(UNCLEAR))
                if confidence < self.min_confidence:
                    return Success(Unclear("low confidence"))
                return Success(Said(run.output, message))
            case Failure(e):
                return Failure(e)
            case _:
                unreachable()
```

+
+Models read the text; the policy decides. A turn runs through two pipelines:
+

+

+from pydantic_ai.models.bedrock import BedrockConverseModel   # or any model pydantic-ai supports

+

+What each part does when something goes wrong (it always errs toward asking again, never toward deciding):
+
+| Situation | Result |
+|---|---|
+| An answer's quote isn't in the message, its value has the wrong type, or it contradicts an opening "yes"/"no" | `Unclear`: the question is asked again |
+| A stated fact can't be quoted, or Jev's confidence is under `min_confidence` (0.5) | the fact is dropped (`Turn.rejected`) |

+| The fact reader fails | the turn goes on without volunteered facts (`Turn.degraded`) |
