# policyproof milestone 3 (the evaluation harness): implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `policyproof eval`: run a user's cases through the milestone 2 pipelines for each reader configuration,
grade every run (correct, conservative, wrong), and gate a deployment on zero wrong cases; plus per-value phrasings in
the policy format.

**Architecture:** `policyproof.eval` has pure modules (`cases`, `grade`, `report`: the core and guards only), an
effectful runner with no SDK (`run`), and the only modules that build models (`config`, `cli`). The runner reduces each
pipeline result to an observation that the pure grader understands, plus trace lines for the report.

**Tech Stack:** Python >= 3.13, uv, pydantic-ai-slim 2.54+ (for `config`), returns, PyYAML; ty, ruff, pytest,
Hypothesis, import-linter.

**Spec:** `docs/specs/2026-10-08-eval-design.md` (see its section "Refinements from prototyping the plan").

**Provenance:** every code block below ran on 2026-10-08 in a scratch copy, one commit per task, and each task's end
state was checked on its own (ruff, ty, import-linter, full suite). At the end: 318 tests pass, 6 import
contracts are kept, and on Bedrock Claude Haiku 4.5 the live tests pass and the toy and flight examples pass their
gates. Diffs are against the previous task's end state.

## Global Constraints

- `requires-python = ">=3.13"`; ruff line length 120; ty must be clean on `src` and `tests`.
- No new runtime dependency. `eval.config` and `eval.cli` need the `[llm]` extra at run time (and `[jev]` for
  `typesafe:` models); `eval.cli` imports `eval.config` only when it runs, so a missing extra is exit code 2.
- Import contracts: `eval.cases`, `eval.grade` and `eval.report` import no `policyproof.effects`, pydantic or SDK;
  `eval.run` imports no `effects.llm`, `effects.jev`, pydantic or SDK.
- Style as before: frozen, slotted dataclasses; closed unions with `match` ending in `assert_never`; a
  `Success`/`Failure` match ends in `case _: unreachable()`; `returns` `Result` for every expected failure.
- Tests call async code with `asyncio.run`. Live tests are marked `live` and excluded by default.
- Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

Inputs a person will meet that the spec doesn't name. Each has a test in the task that owns the code:

1. `--runs 0` or `--concurrency 0`: exit 2 before any model call (and `evaluate` raises `ValueError`), instead of a
   vacuous pass or a hang (`test_bad_options_exit_2_before_any_model_is_called`, Task 8;
   `test_runs_and_concurrency_must_be_positive`, Task 6).
2. A case file with no cases: exit 2, not a vacuous PASS (`test_a_case_file_without_cases_exits_2`, Task 8).
3. `--json` into a directory that doesn't exist: exit 2 before the paid run, not a crash after it (Task 8).
4. `--only` with a configuration whose other models can't be built (e.g. no Jev key): only the selected
   configurations' models are built (`test_only_builds_the_selected_configurations_models`, Task 8;
   `test_only_the_models_a_configuration_uses_are_built`, Task 7).
5. A case message YAML reads as a value (`message: Yes`): a case error asking to quote it
   (`test_bad_cases_name_the_path`, the `expected text` row, Task 3).

```python
from dataclasses import replace

import yaml
from conftest import POLICIES

from policyproof.core.codec import DecodeError, IllTyped, from_yaml, to_yaml
from policyproof.core.syntax import BoolLit, EnumLit, IntLit, RealLit
from policyproof.core.typecheck import BadPhrasings, SortMismatch, check_policy
from policyproof.schema import load

TOY = (POLICIES / "toy.yaml").read_text()
WANTS = "    description: True if the customer wants a refund rather than a voucher.\n"


def with_phrasings(block: str, after: str = WANTS) -> str:
    return TOY.replace(after, after + block)


def var(p, name):
    return next(v for v in p.variables if v.name == name)


def test_phrasings_decode_per_value():
    p = from_yaml(with_phrasings("    phrasings:\n      true: [money back, a refund]\n"
                                 "      false: [a voucher is fine]\n")).unwrap()
    assert var(p, "wantsRefund").phrasings == ((BoolLit(True), ("money back", "a refund")),
                                               (BoolLit(False), ("a voucher is fine",)))


def test_enum_keys_may_be_qualified():
    text = TOY.replace("carrier: { sort: Carrier, role: system, description: Who delivered the parcel. }",
                       "carrier:\n    sort: Carrier\n    role: system\n    description: Who delivered the parcel.\n"
                       "    phrasings: { Carrier.POST: [by post], COURIER: [a courier] }")
    p = from_yaml(text).unwrap()
    assert var(p, "carrier").phrasings == ((EnumLit("Carrier", "POST"), ("by post",)),
                                           (EnumLit("Carrier", "COURIER"), ("a courier",)))


@pytest.mark.parametrize(("block", "path", "message"), [
    ("    phrasings:\n      maybe: [x]\n", "variables.wantsRefund.phrasings.maybe", "not a Bool value"),
    ("    phrasings:\n      true: []\n", "variables.wantsRefund.phrasings.true", "at least one"),
    ("    phrasings:\n      true: ['  ']\n", "variables.wantsRefund.phrasings.true[0]", "empty"),
    ("    phrasings: [money back]\n", "variables.wantsRefund.phrasings", "expected a map"),
])
def test_bad_phrasings_are_decode_errors(block, path, message):
    got = from_yaml(with_phrasings(block))
    assert isinstance(got, Failure)
    err = got.failure()
    assert isinstance(err, DecodeError) and err.path == path and message in err.message, err


def test_int_and_real_keys():
    weights = (POLICIES / "weights.yaml").read_text().replace(
        "description: Weight in kilograms. }",
        'description: Weight in kilograms., phrasings: { "2.5": [two and a half] } }')
    p = from_yaml(weights).unwrap()
    assert var(p, "kg").phrasings == ((RealLit(Fraction(5, 2)), ("two and a half",)),)
    late = from_yaml(TOY.replace("description: Days the parcel arrived after the promised date. }",
                                 "description: Days the parcel arrived after the promised date.,"
                                 " phrasings: { 3: [three days] } }")).unwrap()
    assert var(late, "daysLate").phrasings == ((IntLit(3), ("three days",)),)


def test_derived_variables_cannot_have_phrasings():
    text = TOY.replace("refund: { sort: Bool, role: derived, description: The customer gets a refund. }",
                       "refund: { sort: Bool, role: derived, description: The customer gets a refund.,"
                       " phrasings: { true: [refunded] } }")
    got = from_yaml(text)
    assert got == Failure(IllTyped((BadPhrasings("refund", "a derived variable can't have phrasings"),)))


def test_check_policy_checks_phrasings_built_in_python():
    p = from_yaml(TOY).unwrap()
    bad = replace(var(p, "wantsRefund"), phrasings=((IntLit(1), ("one",)),))
    got = check_policy(replace(p, variables=tuple(bad if v.name == "wantsRefund" else v for v in p.variables)))
    assert isinstance(got, Failure) and isinstance(got.failure()[0], SortMismatch)
    empty = replace(var(p, "wantsRefund"), phrasings=((BoolLit(True), ()),))
    got = check_policy(replace(p, variables=tuple(empty if v.name == "wantsRefund" else v for v in p.variables)))
    assert got == Failure((BadPhrasings("wantsRefund", "each value needs at least one non-empty phrasing"),))


def test_phrasings_round_trip_and_satisfy_the_schema():
    block = "    phrasings:\n      true: [money back]\n      false: [a voucher is fine]\n"
    p = from_yaml(with_phrasings(block)).unwrap()
    assert from_yaml(to_yaml(p)) == Success(p)
    jsonschema.validate(yaml.safe_load(to_yaml(p)), load())
```

```python
"""Evaluation cases: what a user expects of a turn or a reply, read from a YAML file next to their policy.

Every case is checked against the policy before anything runs, so a typo in a case file never costs a model call.
Errors name the YAML path of the problem, e.g. `cases[3].turn.facts.daysLate`.
"""
import re
from collections.abc import Callable, Mapping
from dataclasses import dataclass
from pathlib import Path
from typing import Literal

import yaml
from returns.result import Failure, Result, Success

from policyproof.core._result import sequence
from policyproof.core.codec import from_yaml
from policyproof.core.facts import Answered, Fact, Facts, FromSystem, facts
from policyproof.core.syntax import Ask, CheckedPolicy, Derived, Lit, System
from policyproof.guards.values import literal_for

ID = re.compile(r"[A-Za-z0-9_-]+\Z")


@dataclass(frozen=True, slots=True)
class OutcomeExpected:
    name: str


@dataclass(frozen=True, slots=True)
class AskExpected:
    var: str


@dataclass(frozen=True, slots=True)
class EscalateExpected:
    pass


type ExpectDecision = OutcomeExpected | AskExpected | EscalateExpected


@dataclass(frozen=True, slots=True)
class TurnCase:
    id: str
    held_out: bool
    facts: Facts
    asked: str | None
    message: str
    expect: ExpectDecision
    expect_facts: tuple[tuple[str, Lit], ...]


@dataclass(frozen=True, slots=True)
class ReplyCase:
    id: str
    held_out: bool
    facts: Facts
    draft: str
    expect: Literal["caught", "pass"]


type Case = TurnCase | ReplyCase


@dataclass(frozen=True, slots=True)
class CaseFile:
    policy: CheckedPolicy
    source: str  # the policy file, as given (resolved against the case file)
    cases: tuple[Case, ...]


@dataclass(frozen=True, slots=True)
class CaseError:
    path: str
    message: str

    def __str__(self) -> str:
        return f"{self.path or '<root>'}: {self.message}"


def _err[T](path: str, message: str) -> Result[T, CaseError]:
    return Failure(CaseError(path, message))


def _map(x: object, path: str, allowed: set[str], required: set[str]) -> Result[Mapping[str, object], CaseError]:
    if not isinstance(x, dict):
        return _err(path, "expected a map")
    for k in x:
        if k not in allowed:
            return _err(f"{path}.{k}" if path else str(k), f"unknown key {k!r}")
    for k in sorted(required - x.keys()):
        return _err(path, f"missing required key {k!r}")
    return Success(x)


def _text(x: object, path: str) -> Result[str, CaseError]:
    if isinstance(x, str):
        return Success(x)
    return _err(path, "expected text (YAML reads yes/no/true/false and numbers as values: quote the text)")


def _given(p: CheckedPolicy, x: object, path: str) -> Result[Facts, CaseError]:
    """Facts the case gives: a system variable's value comes from a system, an askable one was answered."""
    if x is None:
        return Success({})
    if not isinstance(x, dict):
        return _err(path, "expected a map of variable: value")

    def one(var: str, value: object) -> Result[Fact, CaseError]:
        at = f"{path}.{var}"
        v = next((v for v in p.variables if v.name == var), None)
        if v is None:
            return _err(at, f"unknown variable {var!r}")
        match v.role:
            case Derived():
                return _err(at, f"{var} is derived by the rules; a case can't give it")
            case System():
                provenance: FromSystem | Answered = FromSystem("case")
            case Ask(question, _):
                provenance = Answered(question, "case")
        return literal_for(p, var, value).alt(lambda m: CaseError(at, m)).map(lambda lit: Fact(var, lit, provenance))
    return sequence(one(str(k), v) for k, v in x.items()).map(lambda fs: facts(*fs))


def _asked(p: CheckedPolicy, x: object, path: str) -> Result[str, CaseError]:
    def check(var: str) -> Result[str, CaseError]:
        v = next((v for v in p.variables if v.name == var), None)
        if v is not None and isinstance(v.role, Ask):
            return Success(var)
        return _err(path, f"{var!r} is not an ask variable")
    return _text(x, path).bind(check)


def _decision(p: CheckedPolicy, x: object, path: str) -> Result[ExpectDecision, CaseError]:
    outcomes = {o.name for o in p.outcomes}
    match x:
        case str() if x in outcomes:
            return Success(OutcomeExpected(x))
        case "escalate":
            return Success(EscalateExpected())
        case str():
            return _err(path, f"unknown outcome {x!r} (outcomes: {', '.join(sorted(outcomes)) or 'none'})")
        case dict():
            return _map(x, path, {"ask"}, {"ask"}).bind(
                lambda m: _asked(p, m["ask"], f"{path}.ask")).map(AskExpected)
        case _:
            return _err(path, "expected an outcome name, {ask: <variable>} or escalate")


def _expected_facts(p: CheckedPolicy, x: object, path: str) -> Result[tuple[tuple[str, Lit], ...], CaseError]:
    if x is None:
        return Success(())
    if not isinstance(x, dict):
        return _err(path, "expected a map of variable: value")
    return sequence(literal_for(p, str(k), v).alt(lambda m, k=k: CaseError(f"{path}.{k}", m)).map(
        lambda lit, k=k: (str(k), lit)) for k, v in x.items())


def _turn(p: CheckedPolicy, cid: str, held: bool, body: object, expect: object, path: str
          ) -> Result[TurnCase, CaseError]:
    at = f"{path}.turn"
    return _map(body, at, {"facts", "asked", "message"}, {"message"}).bind(lambda t: _map(
        expect, f"{path}.expect", {"decision", "facts"}, {"decision"}).bind(lambda e: _given(
            p, t.get("facts"), f"{at}.facts").bind(lambda given: (
                Success(None) if t.get("asked") is None else _asked(p, t["asked"], f"{at}.asked")).bind(
                lambda asked: _text(t["message"], f"{at}.message").bind(lambda message: _decision(
                    p, e["decision"], f"{path}.expect.decision").bind(lambda decision: _expected_facts(
                        p, e.get("facts"), f"{path}.expect.facts").map(lambda want: TurnCase(
                            cid, held, given, asked, message, decision, want))))))))


def _reply(p: CheckedPolicy, cid: str, held: bool, body: object, expect: object, path: str
           ) -> Result[ReplyCase, CaseError]:
    at = f"{path}.reply"
    if expect not in ("caught", "pass"):
        return _err(f"{path}.expect", "a reply case expects caught or pass")
    verdict: Literal["caught", "pass"] = "caught" if expect == "caught" else "pass"
    return _map(body, at, {"facts", "draft"}, {"draft"}).bind(lambda r: _given(p, r.get("facts"), f"{at}.facts").bind(
        lambda given: _text(r["draft"], f"{at}.draft").map(lambda draft: ReplyCase(cid, held, given, draft, verdict))))


def _case(p: CheckedPolicy, x: object, path: str) -> Result[Case, CaseError]:
    def build(m: Mapping[str, object]) -> Result[Case, CaseError]:
        cid = m["id"]
        if not isinstance(cid, str) or not ID.match(cid):
            return _err(f"{path}.id", "an id is letters, digits, - and _")
        held = m.get("held_out", False)
        if not isinstance(held, bool):
            return _err(f"{path}.held_out", "expected true or false")
        if ("turn" in m) == ("reply" in m):
            return _err(path, "a case has exactly one of turn or reply")
        make: Callable[..., Result[Case, CaseError]] = _turn if "turn" in m else _reply
        return make(p, cid, held, m.get("turn", m.get("reply")), m["expect"], path)
    return _map(x, path, {"id", "held_out", "turn", "reply", "expect"}, {"id", "expect"}).bind(build)


def _cases(p: CheckedPolicy, x: object) -> Result[tuple[Case, ...], CaseError]:
    if not isinstance(x, list):
        return _err("cases", "expected a list of cases")
    seen: set[str] = set()
    for i, c in enumerate(x):
        cid = c.get("id") if isinstance(c, dict) else None
        if isinstance(cid, str) and cid in seen:
            return _err(f"cases[{i}].id", f"duplicate id {cid!r}")
        if isinstance(cid, str):
            seen.add(cid)
    return sequence(_case(p, c, f"cases[{i}]") for i, c in enumerate(x))


def _policy(source: str, base: Path) -> Result[CheckedPolicy, CaseError]:
    path = base / source
    try:
        text = path.read_text()
    except OSError as e:
        return _err("policy", f"can't read {path}: {e.strerror}")
    return from_yaml(text).alt(lambda e: CaseError("policy", f"{path}: {e}"))


def decode(data: object, base: Path) -> Result[CaseFile, CaseError]:
    """A case file from plain data (as from `yaml.safe_load`); the policy path is relative to `base`."""
    return _map(data, "", {"policy", "cases"}, {"policy", "cases"}).bind(lambda m: _text(m["policy"], "policy").bind(
        lambda source: _policy(source, base).bind(lambda p: _cases(p, m["cases"]).map(
            lambda cs: CaseFile(p, str(base / source), cs)))))


def load(path: Path) -> Result[CaseFile, CaseError]:
    try:
        data = yaml.safe_load(path.read_text())
    except OSError as e:
        return _err("", f"can't read {path}: {e.strerror}")
    except yaml.YAMLError as e:
        return _err("", f"invalid YAML: {e}")
    return decode(data, path.parent)
```

```python
"""Grading one run of a case: correct, conservative (it asked again, escalated, or fell back) or wrong (it decided
the wrong thing, misread a fact, or let a bad draft through). Pure: the runner reduces what the pipelines returned to
the observations below, so grading needs nothing but the core.
"""
from collections.abc import Iterable
from dataclasses import dataclass
from typing import assert_never

from policyproof.core.decide import Contradiction, Decided, Decision, Escalate, InvalidFacts, NeedInfo
from policyproof.core.facts import Facts
from policyproof.core.render import pretty
from policyproof.eval.cases import AskExpected, EscalateExpected, OutcomeExpected, ReplyCase, TurnCase


@dataclass(frozen=True, slots=True)
class Correct:
    pass


@dataclass(frozen=True, slots=True)
class Conservative:
    reason: str


@dataclass(frozen=True, slots=True)
class Wrong:
    reason: str


type Grade = Correct | Conservative | Wrong


@dataclass(frozen=True, slots=True)
class TurnSeen:
    """What a turn produced: its decision and every fact it ended with."""
    decision: Decision
    facts: Facts


@dataclass(frozen=True, slots=True)
class ReaderFailed:
    """The turn failed with a reader error (`LLMError`)."""
    reason: str


@dataclass(frozen=True, slots=True)
class Crashed:
    """A reader raised an exception: a bug that would reach a customer."""
    reason: str


@dataclass(frozen=True, slots=True)
class ReplySeen:
    as_written: bool  # the draft was sent unchanged


type TurnOutcome = TurnSeen | ReaderFailed | Crashed
type ReplyOutcome = ReplySeen | Crashed


def rank(g: Grade) -> int:
    match g:
        case Correct():
            return 0
        case Conservative():
            return 1
        case Wrong():
            return 2
        case _:
            assert_never(g)


def worst(grades: Iterable[Grade]) -> Grade:
    """The worst grade (the first of equals), or `Correct()` for none."""
    found: Grade = Correct()
    for g in grades:
        if rank(g) > rank(found):
            found = g
    return found


def _instead(d: Decision) -> str:
    match d:
        case NeedInfo(var, _, _, _):
            return f"asked about {var}"
        case Escalate(reason):
            return f"escalated ({reason})"
        case Contradiction():
            return "found a contradiction"
        case Decided(outcome, _, _):
            return f"decided {outcome}"
        case InvalidFacts(errors):
            return f"invalid facts: {'; '.join(errors)}"
        case _:
            assert_never(d)


def _decision(case: TurnCase, d: Decision) -> Grade:
    if isinstance(d, InvalidFacts):
        return Wrong(f"invalid facts reached the decision: {'; '.join(d.errors)}")
    expect = case.expect
    match expect:
        case OutcomeExpected(name):
            match d:
                case Decided(outcome, _, _) if outcome == name:
                    return Correct()
                case Decided(outcome, _, _):
                    return Wrong(f"decided {outcome}, expected {name}")
                case _:
                    return Conservative(f"{_instead(d)} instead of deciding {name}")
        case AskExpected(var):
            match d:
                case NeedInfo(asked, _, _, _) if asked == var:
                    return Correct()
                case NeedInfo(asked, _, _, _):
                    return Conservative(f"asked about {asked}, expected {var}")
                case Decided(outcome, _, _):
                    return Wrong(f"decided {outcome}, expected a question about {var}")
                case _:
                    return Conservative(f"{_instead(d)} instead of asking about {var}")
        case EscalateExpected():
            match d:
                case Escalate() | Contradiction():
                    return Correct()
                case Decided(outcome, _, _):
                    return Wrong(f"decided {outcome}, expected an escalation")
                case _:
                    return Conservative(f"{_instead(d)} instead of escalating")
        case _:
            assert_never(expect)


def _facts(case: TurnCase, fs: Facts) -> Grade:
    grades: list[Grade] = []
    for var, want in case.expect_facts:
        read = {f.value for f in fs.get(var, frozenset())}
        if not read:
            grades.append(Conservative(f"{var} was not read"))
        elif read != {want}:
            got = ", ".join(sorted(pretty(v) for v in read - {want}))
            grades.append(Wrong(f"misread {var}: read {got}, expected {pretty(want)}"))
    return worst(grades)


def grade_turn(case: TurnCase, seen: TurnOutcome) -> Grade:
    match seen:
        case TurnSeen(decision, fs):
            return worst([_facts(case, fs), _decision(case, decision)])
        case ReaderFailed(reason):
            return Conservative(f"reader error: {reason}")
        case Crashed(reason):
            return Wrong(f"crashed: {reason}")
        case _:
            assert_never(seen)


def grade_reply(case: ReplyCase, seen: ReplyOutcome) -> Grade:
    match seen:
        case Crashed(reason):
            return Wrong(f"crashed: {reason}")
        case ReplySeen(as_written):
            if case.expect == "caught":
                return Wrong("the draft was sent as written, expected it to be caught") if as_written else Correct()
            return Correct() if as_written else Conservative("a good draft was rewritten or replaced")
        case _:
            assert_never(seen)
```

```python
"""The evaluation report: per reader configuration, every case's grade (the worst of its runs), totals, held-out
totals, the gate, and the text and JSON forms of all of it. Pure.
"""
import json
from collections.abc import Sequence
from dataclasses import dataclass
from typing import assert_never

from returns.result import Failure, Result, Success

from policyproof.eval.grade import Conservative, Correct, Grade, Wrong, worst


@dataclass(frozen=True, slots=True)
class RunResult:
    run: int  # 1-based
    grade: Grade
    seconds: float
    trace: tuple[str, ...]  # what the run did, as lines of text (written by the runner)


@dataclass(frozen=True, slots=True)
class CaseResult:
    case: str
    held_out: bool
    grade: Grade  # the worst over its runs
    runs: tuple[RunResult, ...]


@dataclass(frozen=True, slots=True)
class Totals:
    correct: int
    conservative: int
    wrong: int  # counts of cases

    @property
    def cases(self) -> int:
        return self.correct + self.conservative + self.wrong


@dataclass(frozen=True, slots=True)
class ConfigurationResult:
    name: str
    cases: tuple[CaseResult, ...]
    totals: Totals
    held_out: Totals


@dataclass(frozen=True, slots=True)
class Report:
    policy: str
    runs: int
    configurations: tuple[ConfigurationResult, ...]


@dataclass(frozen=True, slots=True)
class GateResult:
    passed: bool
    reasons: tuple[str, ...]  # why it failed; empty when it passed


def case_result(case: str, held_out: bool, runs: tuple[RunResult, ...]) -> CaseResult:
    return CaseResult(case, held_out, worst(r.grade for r in runs), runs)


def totals(cases: Sequence[CaseResult]) -> Totals:
    kinds = [type(c.grade) for c in cases]
    return Totals(kinds.count(Correct), kinds.count(Conservative), kinds.count(Wrong))


def configuration_result(name: str, cases: Sequence[CaseResult]) -> ConfigurationResult:
    return ConfigurationResult(name, tuple(cases), totals(cases), totals([c for c in cases if c.held_out]))


def _plural(n: int, word: str) -> str:
    return f"{n} {word}" if n == 1 else f"{n} {word}s"


def _share(t: Totals) -> float:
    return t.conservative / t.cases if t.cases else 0.0


def _gate_reasons(t: Totals, max_conservative: float, prefix: str) -> list[str]:
    reasons: list[str] = []
    if t.wrong:
        reasons.append(f"{prefix}{_plural(t.wrong, 'wrong case')}")
    if _share(t) > max_conservative:
        reasons.append(f"{prefix}{_share(t):.0%} conservative (max {max_conservative:.0%})")
    return reasons


def gate(r: ConfigurationResult, max_conservative: float = 0.1) -> GateResult:
    """Zero wrong cases and at most `max_conservative` of them conservative, over all cases and over the held-out
    cases alone (with no held-out cases, that half passes)."""
    reasons = _gate_reasons(r.totals, max_conservative, "") + _gate_reasons(r.held_out, max_conservative, "held out: ")
    return GateResult(not reasons, tuple(reasons))


# ---- text


def _label(g: Grade) -> str:
    match g:
        case Correct():
            return "correct"
        case Conservative(reason):
            return f"conservative: {reason}"
        case Wrong(reason):
            return f"wrong: {reason}"
        case _:
            assert_never(g)


def _counts(t: Totals) -> str:
    return f"{_plural(t.cases, 'case')}: {t.correct} correct, {t.conservative} conservative, {t.wrong} wrong"


def _case_lines(c: CaseResult) -> list[str]:
    held = " (held out)" if c.held_out else ""
    head = (f"  WRONG {c.case}{held}: {c.grade.reason}" if isinstance(c.grade, Wrong)
            else f"  conservative {c.case}{held}: {c.grade.reason}" if isinstance(c.grade, Conservative) else "")
    lines = [head]
    for r in c.runs:
        lines.append(f"    run {r.run} ({r.seconds:.1f}s): {_label(r.grade)}")
        if not isinstance(r.grade, Correct):
            lines += [f"      {t}" for t in r.trace]
    return lines


def render_text(report: Report, max_conservative: float = 0.1) -> str:
    lines = [f"policy {report.policy}, {_plural(report.runs, 'run')} per case"]
    for r in report.configurations:
        g = gate(r, max_conservative)
        lines += ["", f"{r.name}: PASS" if g.passed else f"{r.name}: FAIL ({'; '.join(g.reasons)})",
                  f"  {_counts(r.totals)} ({_share(r.totals):.0%} conservative, max {max_conservative:.0%})"]
        if r.held_out.cases:
            lines.append(f"  held out: {_counts(r.held_out)}")
        for kind in (Wrong, Conservative):
            for c in r.cases:
                if isinstance(c.grade, kind):
                    lines += _case_lines(c)
    return "\n".join(lines) + "\n"


# ---- JSON


def _grade_data(g: Grade) -> dict[str, str]:
    match g:
        case Correct():
            return {"grade": "correct"}
        case Conservative(reason):
            return {"grade": "conservative", "reason": reason}
        case Wrong(reason):
            return {"grade": "wrong", "reason": reason}
        case _:
            assert_never(g)


def to_json(report: Report) -> str:
    return json.dumps({"policy": report.policy, "runs": report.runs, "configurations": [
        {"name": r.name, "cases": [
            {"case": c.case, "held_out": c.held_out, "runs": [
                {"run": x.run, **_grade_data(x.grade), "seconds": x.seconds, "trace": list(x.trace)} for x in c.runs]}
            for c in r.cases]}
        for r in report.configurations]}, indent=1)


def _grade(d: dict[str, object]) -> Grade:
    match d["grade"]:
        case "correct":
            return Correct()
        case "conservative":
            return Conservative(str(d["reason"]))
        case "wrong":
            return Wrong(str(d["reason"]))
        case other:
            raise ValueError(f"unknown grade {other!r}")


def from_json(text: str) -> Result[Report, str]:
    """A report written by `to_json`. Totals and case grades are recomputed from the runs."""
    try:
        data = json.loads(text)
        return Success(Report(str(data["policy"]), int(data["runs"]), tuple(
            configuration_result(str(r["name"]), [
                case_result(str(c["case"]), bool(c["held_out"]), tuple(
                    RunResult(int(x["run"]), _grade(x), float(x["seconds"]), tuple(str(t) for t in x["trace"]))
                    for x in c["runs"]))
                for c in r["cases"]])
            for r in data["configurations"])))
    except (ValueError, KeyError, TypeError) as e:
        return Failure(f"not a report: {type(e).__name__}: {e}")
```

```python
"""Running cases through the turn pipelines, for each reader configuration, and grading every run.

A turn case starts from its given facts and pending question and runs `read_turn` on its message. A reply case decides
from its facts and runs `guard_reply` on its draft. Each run is reduced to what grading needs (`eval.grade`) plus a
few lines of trace for the report. An exception from a reader is a bug: the run is graded wrong and the rest go on.
"""
import asyncio
import time
from collections.abc import Sequence
from dataclasses import dataclass
from typing import assert_never

from returns.result import Failure, Success

from policyproof.core._result import unreachable
from policyproof.core.decide import (
    Contradiction,
    Decided,
    Decision,
    Escalate,
    InvalidFacts,
    NeedInfo,
    decide,
    firm_facts,
    what_if,
)
from policyproof.core.facts import Answered, Fact, FromSystem, Quoted, Scored, Volunteered, all_facts
from policyproof.core.render import pretty
from policyproof.core.solver import Compiled, compile
from policyproof.core.syntax import Ask
from policyproof.effects.errors import describe
from policyproof.effects.pipeline import Conversation, Guarded, Readers, Turn, guard_reply, read_turn
from policyproof.effects.ports import AnswerReader, ClaimReader, FactReader, NotAnswered, Rewriter, Unclear
from policyproof.eval.cases import Case, CaseFile, ReplyCase, TurnCase
from policyproof.eval.grade import Crashed, Grade, ReaderFailed, ReplySeen, TurnSeen, grade_reply, grade_turn
from policyproof.eval.report import Report, RunResult, case_result, configuration_result
from policyproof.guards.answer import Answer, Reading


@dataclass(frozen=True, slots=True)
class Configuration:
    """One way of reading text: built by `eval.config` from readers.yaml, or by hand."""
    name: str
    answers: AnswerReader
    facts: FactReader
    claims: ClaimReader
    rewriter: Rewriter
    min_confidence: float = 0.5
    firm_confidence: float = 0.8


def _decision_line(d: Decision) -> str:
    match d:
        case Decided(outcome, rules, _):
            return f"decision: decided {outcome} (rules {', '.join(rules)})"
        case NeedInfo(var, _, reason, _):
            return f"decision: asks about {var} ({reason})"
        case Escalate(reason):
            return f"decision: escalates ({reason})"
        case Contradiction(rules, _):
            return f"decision: contradiction (rules {', '.join(rules)})"
        case InvalidFacts(errors):
            return f"decision: invalid facts ({'; '.join(errors)})"
        case _:
            assert_never(d)


def _source(f: Fact) -> str:
    match f.provenance:
        case FromSystem(source):
            return f"from {source}"
        case Answered(_, quote):
            return f'answered: "{quote}"'
        case Volunteered(Quoted(text)):
            return f'said: "{text}"'
        case Volunteered(Scored(confidence)):
            return f"scored {confidence:.2f}"
        case _:
            unreachable()


def _answer_line(r: Reading) -> str:
    match r:
        case Answer(fact):
            return f"answer: {fact.var} = {pretty(fact.value)}"
        case Unclear(reason):
            return f"answer unclear: {reason}"
        case NotAnswered():
            return "not answered"
        case _:
            assert_never(r)


def _turn_trace(case: TurnCase, t: Turn) -> tuple[str, ...]:
    given = set(all_facts(case.facts))
    lines = [_decision_line(t.decision)]
    lines += [f"read {f.var} = {pretty(f.value)} ({_source(f)})" for f in all_facts(t.state.facts) if f not in given]
    lines += [_answer_line(t.answer)] if t.answer is not None else []
    lines += [f"rejected {r.item}: {r.reason}" for r in t.rejected]
    lines += [f"degraded: {describe(e)}" for e in t.degraded]
    return tuple(lines)


def _reply_trace(g: Guarded) -> tuple[str, ...]:
    if g.fell_back:
        head = f"fell back ({g.reason}): {g.text}"
    elif g.attempts == 1:
        head = f"sent as written: {g.text}"
    else:
        head = f"sent after {g.attempts} attempts: {g.text}"
    lines = [head]
    if g.result is not None:
        lines += [f'claim "{r.claim.quote}": {pretty(r.claim.expr)} is {r.status.replace("_", " ")}'
                  for r in g.result.claims]
        lines += [f"problem ({p.rule}): {p.message}" for p in g.result.problems]
    return tuple(lines)


def _pending(c: Compiled, case: TurnCase) -> NeedInfo | None:
    if case.asked is None:
        return None
    role = next(v.role for v in c.policy.variables if v.name == case.asked)
    assert isinstance(role, Ask)
    return NeedInfo(case.asked, role.question, "missing", what_if(c, firm_facts(c, case.facts), case.asked))


async def _turn(c: Compiled, cfg: Configuration, case: TurnCase) -> tuple[Grade, tuple[str, ...]]:
    state = Conversation(case.facts, _pending(c, case), frozenset())
    try:
        result = await read_turn(c, state, case.message, Readers(cfg.answers, cfg.facts),
                                 min_confidence=cfg.min_confidence, firm_confidence=cfg.firm_confidence)
    except Exception as e:
        crash = f"{type(e).__name__}: {e}"
        return grade_turn(case, Crashed(crash)), (f"crashed: {crash}",)
    match result:
        case Success(t):
            return grade_turn(case, TurnSeen(t.decision, t.state.facts)), _turn_trace(case, t)
        case Failure(e):
            return grade_turn(case, ReaderFailed(describe(e))), (f"reader error: {describe(e)}",)
        case _:
            unreachable()


async def _reply(c: Compiled, cfg: Configuration, case: ReplyCase) -> tuple[Grade, tuple[str, ...]]:
    d = decide(c, case.facts)
    try:
        g = await guard_reply(c, case.facts, d, case.draft, cfg.claims, cfg.rewriter)
    except Exception as e:
        crash = f"{type(e).__name__}: {e}"
        return grade_reply(case, Crashed(crash)), (f"crashed: {crash}",)
    seen = ReplySeen(as_written=not g.fell_back and g.attempts == 1)
    return grade_reply(case, seen), (_decision_line(d), *_reply_trace(g))


async def _job(c: Compiled, cfg: Configuration, case: Case, run: int, limit: asyncio.Semaphore) -> RunResult:
    async with limit:
        start = time.perf_counter()
        match case:
            case TurnCase():
                grade, trace = await _turn(c, cfg, case)
            case ReplyCase():
                grade, trace = await _reply(c, cfg, case)
            case _:
                assert_never(case)
        return RunResult(run, grade, round(time.perf_counter() - start, 2), trace)


async def evaluate(f: CaseFile, configurations: Sequence[Configuration], *, runs: int = 3,
                   concurrency: int = 4) -> Report:
    if runs < 1 or concurrency < 1:
        raise ValueError(f"runs and concurrency must be at least 1, got runs={runs}, concurrency={concurrency}")
    c = compile(f.policy)
    limit = asyncio.Semaphore(concurrency)
    results = []
    for cfg in configurations:
        per_case = await asyncio.gather(*(
            asyncio.gather(*(_job(c, cfg, case, n, limit) for n in range(1, runs + 1))) for case in f.cases))
        results.append(configuration_result(cfg.name, [
            case_result(case.id, case.held_out, tuple(rs)) for case, rs in zip(f.cases, per_case, strict=True)]))
    return Report(f.policy.name, runs, tuple(results))
```

```python
"""Reader configurations from a YAML file: named models (pydantic-ai model strings) and, for each configuration, which
model reads answers, facts and claims and which rewrites, alone or two at a time (`agree`, `union`).

The whole file is checked before any model is built; building creates one reader per model and needs the `[llm]`
extra (and `[jev]` for `typesafe:` models).
"""
from collections.abc import Mapping
from dataclasses import dataclass
from pathlib import Path
from typing import TYPE_CHECKING

import yaml
from pydantic_ai.models import Model, infer_model
from returns.result import Failure, Result, Success

from policyproof.core._result import sequence
from policyproof.effects.consensus import AgreeingAnswers, AgreeingFacts, UnionClaims
from policyproof.effects.llm.readers import LLMReaders
from policyproof.effects.ports import AnswerReader, ClaimReader, FactReader
from policyproof.eval.run import Configuration

if TYPE_CHECKING:
    from policyproof.effects.jev.readers import JevReaders

JEV_PREFIX = "typesafe:"


@dataclass(frozen=True, slots=True)
class Use:
    model: str


@dataclass(frozen=True, slots=True)
class Agree:
    a: str
    b: str


@dataclass(frozen=True, slots=True)
class UnionOf:
    a: str
    b: str


type Slot = Use | Agree | UnionOf


@dataclass(frozen=True, slots=True)
class ConfigSpec:
    name: str
    answers: Use | Agree
    facts: Use | Agree
    claims: Use | UnionOf
    rewriter: Use
    min_confidence: float = 0.5
    firm_confidence: float = 0.8


@dataclass(frozen=True, slots=True)
class ConfigFile:
    models: Mapping[str, str]
    configurations: tuple[ConfigSpec, ...]


@dataclass(frozen=True, slots=True)
class ConfigError:
    path: str
    message: str

    def __str__(self) -> str:
        return f"{self.path or '<root>'}: {self.message}"


def _err[T](path: str, message: str) -> Result[T, ConfigError]:
    return Failure(ConfigError(path, message))


def _slot(models: Mapping[str, str], x: object, path: str, kind: str) -> Result[Slot, ConfigError]:
    def model(name: object, where: str) -> Result[str, ConfigError]:
        if not isinstance(name, str) or name not in models:
            return _err(where, f"unknown model {name!r} (models: {', '.join(models)})")
        if kind in ("claims", "rewriter") and models[name].startswith(JEV_PREFIX):
            return _err(where, "Jev reads only answers and facts; use a chat model here")
        return Success(name)

    match x:
        case str():
            return model(x, path).map(Use)
        case {"agree": [a, b]} if len(x) == 1:
            if kind not in ("answers", "facts"):
                return _err(path, "claims combine with union; a rewriter is one model" if kind == "claims"
                            else "a rewriter is one model")
            return model(a, path).bind(lambda m1: model(b, path).map(lambda m2: Agree(m1, m2)))
        case {"union": [a, b]} if len(x) == 1:
            if kind != "claims":
                return _err(path, "answers and facts combine with agree" if kind in ("answers", "facts")
                            else "a rewriter is one model")
            return model(a, path).bind(lambda m1: model(b, path).map(lambda m2: UnionOf(m1, m2)))
        case _:
            return _err(path, "expected a model name, {agree: [a, b]} or {union: [a, b]}")


def _confidence(x: object, path: str, default: float) -> Result[float, ConfigError]:
    if x is None:
        return Success(default)
    if isinstance(x, int | float) and not isinstance(x, bool) and 0 <= x <= 1:
        return Success(float(x))
    return _err(path, "a confidence is a number between 0 and 1")


def _spec_of(name: str, a: Slot, f: Slot, c: Slot, r: Slot, lo: float, hi: float) -> ConfigSpec:
    """`_slot` has already refused `union` for answers and facts, `agree` for claims, and both for the rewriter."""
    assert not isinstance(a, UnionOf) and not isinstance(f, UnionOf) and not isinstance(c, Agree)
    assert isinstance(r, Use)
    return ConfigSpec(name, a, f, c, r, lo, hi)


def _spec(models: Mapping[str, str], name: str, x: object, path: str) -> Result[ConfigSpec, ConfigError]:
    keys = {"answers", "facts", "claims", "rewriter", "min_confidence", "firm_confidence"}
    if not isinstance(x, dict):
        return _err(path, "expected a map")
    extra = [k for k in x if k not in keys]
    if extra:
        return _err(f"{path}.{extra[0]}", f"unknown key {extra[0]!r}")
    missing = sorted({"answers", "facts", "claims", "rewriter"} - x.keys())
    if missing:
        return _err(path, f"missing required key {missing[0]!r}")

    def slot(k: str) -> Result[Slot, ConfigError]:
        return _slot(models, x[k], f"{path}.{k}", k)

    return slot("answers").bind(lambda a: slot("facts").bind(lambda f: slot("claims").bind(lambda c: slot(
        "rewriter").bind(lambda r: _confidence(x.get("min_confidence"), f"{path}.min_confidence", 0.5).bind(
            lambda lo: _confidence(x.get("firm_confidence"), f"{path}.firm_confidence", 0.8).map(
                lambda hi: _spec_of(name, a, f, c, r, lo, hi)))))))


def decode_config(data: object) -> Result[ConfigFile, ConfigError]:
    if not isinstance(data, dict) or set(data) != {"models", "configurations"}:
        return _err("", "expected a map with exactly the keys models and configurations")
    models, configs = data["models"], data["configurations"]
    if not isinstance(models, dict) or not isinstance(configs, dict):
        return _err("", "models and configurations are maps")
    for k, v in models.items():
        if not isinstance(v, str):
            return _err(f"models.{k}", "expected a pydantic-ai model string, e.g. bedrock:<model id>")
    return sequence(_spec(models, str(k), v, f"configurations.{k}") for k, v in configs.items()).map(
        lambda specs: ConfigFile(dict(models), specs))


def load_config(path: Path) -> Result[ConfigFile, ConfigError]:
    try:
        data = yaml.safe_load(path.read_text())
    except OSError as e:
        return _err("", f"can't read {path}: {e.strerror}")
    except yaml.YAMLError as e:
        return _err("", f"invalid YAML: {e}")
    return decode_config(data)


def _is_jev(m: Model) -> bool:
    try:
        from pydantic_ai.models.typesafe import TypeSafeModel
    except ImportError:
        return False
    return isinstance(m, TypeSafeModel)


def _jev_reader(m: Model) -> "JevReaders":
    from policyproof.effects.jev.readers import JevReaders  # imported only when a Jev model is used: needs [jev]
    return JevReaders(m)


def build(cf: ConfigFile, models: Mapping[str, Model] | None = None) -> Result[tuple[Configuration, ...], ConfigError]:
    """The configurations, with one reader per model they use (models no configuration uses aren't built).
    `models` replaces model strings (tests pass FunctionModels)."""
    chat: dict[str, LLMReaders] = {}
    jev: dict[str, JevReaders] = {}
    used = {m for s in cf.configurations for slot in (s.answers, s.facts, s.claims, s.rewriter)
            for m in ((slot.model,) if isinstance(slot, Use) else (slot.a, slot.b))}
    for name, spec in cf.models.items():
        if name not in used:
            continue
        try:
            m = models[name] if models is not None and name in models else infer_model(spec)
        except Exception as e:
            return _err(f"models.{name}", f"can't build {spec!r}: {e}")
        if _is_jev(m):
            jev[name] = _jev_reader(m)
        else:
            chat[name] = LLMReaders(m)

    def reads(name: str) -> "LLMReaders | JevReaders":
        return chat[name] if name in chat else jev[name]

    def answers(s: Use | Agree) -> AnswerReader:
        return reads(s.model) if isinstance(s, Use) else AgreeingAnswers(reads(s.a), reads(s.b))

    def facts(s: Use | Agree) -> FactReader:
        return reads(s.model) if isinstance(s, Use) else AgreeingFacts(reads(s.a), reads(s.b))

    built: list[Configuration] = []
    for s in cf.configurations:
        writers = [s.claims.model] if isinstance(s.claims, Use) else [s.claims.a, s.claims.b]
        for name in [*writers, s.rewriter.model]:
            if name not in chat:
                return _err(f"configurations.{s.name}", f"{name} is a Jev model; Jev reads only answers and facts")
        claims: ClaimReader = (chat[s.claims.model] if isinstance(s.claims, Use)
                               else UnionClaims(chat[s.claims.a], chat[s.claims.b]))
        built.append(Configuration(s.name, answers(s.answers), facts(s.facts), claims, chat[s.rewriter.model],
                                   s.min_confidence, s.firm_confidence))
    return Success(tuple(built))
```

```python
"""`policyproof eval CASES --readers READERS`: run the cases for each reader configuration and gate the result.

Exit codes: 0 every selected configuration passes its gate; 1 one fails; 2 the cases, the policy or the reader
configuration is invalid, or an extra is missing. Everything is checked before the first model call.
"""
import argparse
import asyncio
import sys
from collections.abc import Mapping, Sequence
from dataclasses import replace
from pathlib import Path
from typing import TYPE_CHECKING

from returns.result import Failure, Success

from policyproof.core._result import unreachable
from policyproof.eval.cases import load
from policyproof.eval.report import gate, render_text, to_json
from policyproof.eval.run import evaluate

if TYPE_CHECKING:
    from pydantic_ai.models import Model


def _parser() -> argparse.ArgumentParser:
    p = argparse.ArgumentParser(prog="policyproof", description="Prove what an agent may decide and say.")
    sub = p.add_subparsers(dest="command", required=True)
    e = sub.add_parser("eval", help="evaluate reader configurations on a case file and gate the result")
    e.add_argument("cases", type=Path, help="the case file (YAML)")
    e.add_argument("--readers", type=Path, required=True, help="the reader configurations (YAML)")
    e.add_argument("--only", action="append", metavar="NAME", help="run only this configuration (repeatable)")
    e.add_argument("--runs", type=int, default=3, help="runs per case (default 3)")
    e.add_argument("--concurrency", type=int, default=4, help="model calls at once (default 4)")
    e.add_argument("--max-conservative", type=float, default=0.1,
                   help="the largest share of conservative cases the gate allows (default 0.1)")
    e.add_argument("--json", type=Path, metavar="OUT", help="also write the report as JSON")
    return p


def _fail(message: str) -> int:
    print(message, file=sys.stderr)
    return 2


def main(argv: Sequence[str] | None = None, *, models: "Mapping[str, Model] | None" = None) -> int:
    """`models` replaces the configuration's model strings (tests pass scripted models)."""
    args = _parser().parse_args(argv)
    if args.runs < 1:
        return _fail("--runs must be at least 1")
    if args.concurrency < 1:
        return _fail("--concurrency must be at least 1")
    if not 0 <= args.max_conservative <= 1:
        return _fail("--max-conservative must be between 0 and 1")
    if args.json and not args.json.parent.is_dir():
        return _fail(f"can't write the report: {args.json.parent} does not exist")
    match load(args.cases):
        case Failure(err):
            return _fail(f"{args.cases}: {err}")
        case Success(cases) if not cases.cases:
            return _fail(f"{args.cases} has no cases")
        case Success(cases):
            pass
        case _:
            unreachable()
    try:
        from policyproof.eval.config import build, load_config
    except ImportError as e:
        return _fail(f"reading text needs an extra: pip install 'policyproof[llm]' ({e})")
    match load_config(args.readers):
        case Failure(err):
            return _fail(f"{args.readers}: {err}")
        case Success(cf):
            pass
        case _:
            unreachable()
    if args.only:
        names = {s.name for s in cf.configurations}
        unknown = [n for n in args.only if n not in names]
        if unknown:
            return _fail(f"no configuration named {unknown[0]!r} (configurations: {', '.join(sorted(names))})")
        cf = replace(cf, configurations=tuple(s for s in cf.configurations if s.name in args.only))
    match build(cf, models):
        case Failure(err):
            return _fail(f"{args.readers}: {err}")
        case Success(configurations):
            pass
        case _:
            unreachable()
    report = asyncio.run(evaluate(cases, configurations, runs=args.runs, concurrency=args.concurrency))
    print(render_text(report, args.max_conservative), end="")
    if args.json:
        args.json.write_text(to_json(report))
    return 0 if all(gate(r, args.max_conservative).passed for r in report.configurations) else 1


def entry() -> None:
    raise SystemExit(main())
```

+## Evaluating a configuration: `policyproof eval`
+
+Before deploying, check that your readers are safe on your policy. Write cases next to it: a turn case gives the
+known facts, the question pending and the customer's message, and says what must be decided; a reply case gives the
+facts and a draft, and says whether the check must catch it.
+
+```yaml
+policy: policy.yaml
+cases:
+  - id: says-yes
+    turn: {facts: {daysLate: 3}, asked: wantsRefund, message: "Yes please, I'd like my money back."}
+    expect: {decision: refund, facts: {wantsRefund: true}}
+  - id: voucher-draft-is-caught
+    held_out: true
+    reply: {facts: {daysLate: 3, wantsRefund: true}, draft: "You'll get a voucher."}
+    expect: caught
+```
+
+Name your reader configurations (models are pydantic-ai model strings) and run them:
+
+```bash
+policyproof eval cases.yaml --readers readers.yaml --runs 3 --json report.json
+```
+
+Every case runs `--runs` times for each configuration. A run is **correct**, **conservative** (it asked again,
+escalated, or fell back: safe but unhelpful) or **wrong** (it decided the wrong outcome, misread a fact, or let a bad
+draft through), and a case is as bad as its worst run. The gate passes with zero wrong cases and at most
+`--max-conservative` (10%) conservative ones, over all cases and over the held-out cases alone. Exit codes: 0 pass,
+1 fail, 2 invalid input (checked before any model is called).
+
+Write held-out cases last and don't tune against them. `examples/eval/` has cases for the three reference policies
+and a `readers.yaml`. On Bedrock Claude Haiku 4.5 the toy and flight cases pass; the retail held-out case
+`unopened-and-cracked` comes out conservative (the model finds "unopened, but the screen is cracked" contradictory
+and asks again), which is what a failed gate looks like in practice.
+
+Phrasings help readers recognise answers. Add them to a variable in the policy; they never change a decision:
+
+```yaml
+wantsRefund:
+  sort: Bool
+  role: ask
+  question: Would you like your money back?
+  phrasings: {true: [money back, a refund], false: [a voucher is fine]}
+```
